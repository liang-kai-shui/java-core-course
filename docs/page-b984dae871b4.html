本机核对结果

2026-10-27实际运行：java -version与javac -version（通过完整路径）均为21.0.12。安装目录为 C:\Program Files\Java\graalvm-jdk-21.0.12+7.1。当前终端的PATH没有找到这两个命令；不需要重新安装，更不必为学习第10版而降级全局环境。

项目的 .java-course.json 记录本机位置，并由Git忽略。java.ps1优先读它，找不到才依次检查JAVA_HOME、PATH以及常见安装目录。换电脑时可从 .java-course.example.json 复制成本机配置再填写路径。不要把其他项目的配置和机器路径发进公开包。

术语先说清楚

  • JDK：开发Java的工具包，里面有编译器和运行工具。像做菜的一套厨具，不只是拿到成品。
  • JVM：执行Java字节码的虚拟机。可以理解成各个平台提供的“字节码执行员”；它不是完整的电脑模拟器。
  • JRE：Java运行环境这个概念，包括JVM及运行所需的库等。现代JDK的发行形式和书中旧版界面不同，本课程不另找一个“JRE下载”安装。
  • PATH：系统寻找命令的目录清单。命令找不到只表明搜索失败，不证明软件没安装。

先会两步运行

在某个示例目录的PowerShell中，手动执行（例：HelloJava.java）：

$jdk = 'C:\Program Files\Java\graalvm-jdk-21.0.12+7.1'
New-Item -ItemType Directory -Path .\out -Force | Out-Null
& "$jdk\bin\javac.exe" --release 8 -encoding UTF-8 '-Xlint:all,-options' -d .\out .\HelloJava.java
if ($LASTEXITCODE -eq 0) {
    & "$jdk\bin\java.exe" -Dfile.encoding=UTF-8 -Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8 -cp .\out HelloJava
}

javac把源文件变成.class；java按类名启动程序。-d指定编译产物目录；-cp指定从哪里找类；运行时写HelloJava，不带.class。--release 8在当前JDK允许的范围内约束Java8语法与标准API；它不会把JDK21变成JDK8。-Xlint:all,-options启用代码警告，仅关闭旧目标版本的选项提示。

正常学习优先用根目录的 java.ps1：它每次新建隔离输出目录，失败立即停，避免错跑旧class。示例无package且各有独立main，不要把所有课次一次编译到同一个目录。

需要程序参数时：.\java.ps1 -Source '路径\ArgsDemo.java' -ProgramArgs @('red','blue')。-CompileOnly只编译，不声称运行成功。脚本适用Windows PowerShell5.1或PowerShell7；其他系统可用上面同等的javac/java命令，路径按系统修改。

中文输入与输出

源码统一保存UTF-8；编译显式-encoding UTF-8。本机JDK21运行时可设置-Dstdout.encoding=UTF-8和-Dstderr.encoding=UTF-8；项目脚本同时临时设置控制台编码并在退出前恢复。输入示例使用键盘交互，不靠旧PowerShell默认编码的管道传中文。出现乱码时先记录终端、源文件编码和实际命令，别随意重装JDK。

报错时如何判断

编译失败看javac诊断；运行失败看异常类型、第一条指向自己源码的堆栈行和输入；结果错误则列出输入→期望→实际。看到Compilation succeeded只代表编译过了，看到程序自己的输出才说明它实际运行。

编译有错时不要手动继续运行旧class。脚本生成的 .build/ 都是可再生文件，不含你的源码；本项目不自动删除其中内容。
