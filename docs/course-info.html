第一次学习：零基础起飞 → L01 讲义 → 直接在L01练习里作答。

讲义是可以独立学习的正文，PDF教材用于学会之后深化。 每课先用具体问题建立需求，再讲白话概念、拆语法、走完整程序、做单步修改，带到独立练习；完成基础任务不以先读PDF为条件。课程沿教材章节顺序推进，但不会把关键解释留在教材中。不假设你已经会 C++，也不根据“以前看过”推定已经掌握。

现在 L01–L10 已按这个定位重写：讲义中的完整程序可以单独运行，短片段与完整程序分开；执行表、引用图、输入队列和项目阶段帮助理解过程。练习附起步提示，参考答案解释思路与常见错法。材料准备完成仍需通过实际学习与反馈检验，不能保证每个人一遍读完就掌握。

如果你对电脑操作也不熟

先读《零基础起飞》。它从电脑、文件、扩展名、路径讲起，带你打开任务管理器和PowerShell、新建源码、编译运行、观察class文件，再处理中文和旧结果问题。每个阶段都有具体操作、应看到的结果及排错办法，可以分几次完成。

第一次出现的名词，先说清“是什么、为什么需要、可以怎样类比”，再用操作建立认识。类比只帮助理解，不能替代真实规则；不能把“写一行定义”当作已经教会，也不把任务管理器、当前位置、保存等电脑操作默认为人人会。

怎样使用

  1. 第一次先读 零基础起飞、环境说明 和 页码对应说明。
  2. 按讲义的学习段阅读、手敲完整程序，先预测、再运行、解释差异。不会时回到讲义对应步骤；基础练习所需解释由讲义提供。
  3. 在 my_code/ 里新建文件手敲示例，先预测结果再运行；保留原 code/ 示例。
  4. 直接在每课的 练习.md 里写答案，按 Ctrl+S 保存。 代码写入 my_code/，在题目下记录源码路径、命令和结果；不必另建 作答.md。已有作答文件仍可继续使用。
  5. 首次学习时将学习进度模板复制为根目录的 进度追踪.md；已有记录就接续使用。完成后告诉 AI 课号并提供作答，AI 先读进度记录，按批改指南批改。
  6. 按提示订正，复核通过后进入下一课。参考答案在各课 参考答案/，先独立思考再看。想理解得更深时，按讲义末尾“教材深化”的双页码表阅读PDF，对照更正式的论述、更多案例与细节；这不增加基础过关条件。

本书不是按章配置成套习题的入门课本，因此本项目练习均为原创配套题，不是教材原题或官方答案。

本地个人练习与公开课程分开维护：本地 练习.md 保留你的答案；公开网页、压缩包和GitHub发布目录从独立的空白题目模板构建，不会因为重新打包而清掉答案，也不会把你的作答混入公开习题。

快速运行一个示例

在本目录打开 PowerShell：

.\check-java.ps1
.\java.ps1 -Source '.\L01_第01章_认识Java\code\HelloJava.java'

若当前进程的脚本执行策略阻止运行，可用以下单次命令，不改系统执行策略：

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\java.ps1 -Source '.\L01_第01章_认识Java\code\HelloJava.java'

VS Code选择“文件 → 打开文件夹”，打开解压后的课程根目录（能看见 java.ps1 和各课文件夹的那一层）。打开一个本课程独立 .java 文件后按 Ctrl+Shift+B，调用项目任务。

建议使用 JDK 21。项目脚本优先读取 .java-course.json，再检查已有环境和常见安装目录，不修改全局环境；找不到 JDK 时按环境说明填写自己的安装路径。公开版的 jdkHome 留空。示例采用 Java 8 语法/API，课程验证使用 JDK 21 的 --release 8 编译，并在 JDK 21 上运行。java.ps1面向当前无package的单文件程序；后续多文件工程会另设运行入口。

页码约定

每课同时写 书本 pX–Y / PDF pA–B。例如书本 p63 对应本地PDF第81页。正文换算：PDF页 = 书本页 + 18。前置封面、前言、目录不能套用这个公式。

原教材：Java核心技术卷1基础知识原书第10版 .pdf，文件名在 .pdf 前确实带一个空格，保留不变。教材须自备；公开仓库、离线包不含PDF或扫描图片。核对记录与范围边界见 页码对应说明。

学习纪律

先自己写、先预测、再运行。报错保留从第一行开始的完整文本。提交时写明输入、期望、实际结果。卡住时先写出思路，AI默认给提示；你明确需要完整答案时可以直接说明。

不要因为见过C++的相似写法就跳过验证：Java的boolean、字符串比较、数组引用和按值传参都有自己的规则。
