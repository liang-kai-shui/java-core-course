L04 参考答案 · 先独立作答

本文件是课程原创参考，允许其他正确解法。代码与参考答案通过验证不等于学生已通过。

Q1：依次为int的3、double的3.5、double的3.0、int的3。Q2：先发生int乘法溢出再转long，应在乘之前转换一个操作数，或用long操作数。

E1：参考TimeSplit；测试0→0/0/0，59→0/0/59，60→0/1/0，3600→1/0/0。E2：参考Average；分母或分子在除法前为double，不能只将整数商赋给double。E3：&&在divisor为0时短路；换为&则会执行整数除零，编译可过但运行出现ArithmeticException。

编程参考文件

本目录中的.java文件可分别独立运行；部分实验直接对照上级code或error_lab。原始题目和指定输入输出优先于参考实现，发现矛盾应核实后修正。

本目录源码 · 点击展开

Average.java
public class Average {
    public static void main(String[] args) {
        int a = 80;
        int b = 81;
        int c = 82;
        double average = (a + b + c) / 3.0;
        System.out.println(average);
    }
}
TimeSplit.java
public class TimeSplit {
    public static void main(String[] args) {
        int total = 3671;
        int hours = total / 3600;
        int minutes = (total % 3600) / 60;
        int seconds = total % 60;
        System.out.println("hours=" + hours);
        System.out.println("minutes=" + minutes);
        System.out.println("seconds=" + seconds);
    }
}
