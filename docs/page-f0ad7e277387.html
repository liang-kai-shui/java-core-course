对应本课练习。先自己尝试，再看为什么。题目为课程原创；允许其他正确解法，参考程序也需要接受核对。以下是材料解析，不是对学生作答的批改结论。

Q1：值和类型一起写

表达式 结果类型 值 为什么
7/2 int 3 整数除法
7/2.0 double 3.5 除法本身用double
(double)(7/2) double 3.0 整数商先得到3
(int)3.9 int 3 截去小数，不四舍五入

错误若出在第三行，应回到运算发生顺序，不靠更改输出格式修补。

Q2：先乘坏了，再放大盒子无效

两个1000000都是int，乘法先按int发生并溢出。可在乘前把一个操作数转long，或使用1000000L。仅在整个乘积外加(long)，时机仍然太晚。

E1：逐层拆剩余量

参考TimeSplit.java。先总秒数/3600求小时，再用%3600保留未组成整小时的部分；剩余量/60求分钟，%60求秒。

总秒 小时 分钟 秒
0 0 0 0
59 0 0 59
60 0 1 0
3600 1 0 0
3671 1 1 11

检查小时3600+分钟60+秒是否还原原数。这个等式能揭示中间量用错的问题。

E2：用不能整除的总分揭示错法

参考Average.java。让分子或除数在除法前成为double，例如total/3.0。80、81、82刚好整除，不足以揭示整数除法；80、80、81应约为80.3333。

只把接收变量写成double，会把80保存为80.0，丢掉的小数已经不在。

E3：短路改变是否执行右侧

除数0时，&&左边为false，右边不执行，正常得到false。换&后右侧仍执行，发生整数除零ArithmeticException。源码语法可接受，故不属于编译失败。记录真实异常，再恢复正常版，不修改标本原件。

本目录源码 · 点击展开

Average.java
public class Average {
    public static void main(String[] args) {
        int a = 80;
        int b = 81;
        int c = 82;
        double average = (a + b + c) / 3.0;
        System.out.println(average);
    }
}
TimeSplit.java
public class TimeSplit {
    public static void main(String[] args) {
        int total = 3671;
        int hours = total / 3600;
        int minutes = (total % 3600) / 60;
        int seconds = total % 60;
        System.out.println("hours=" + hours);
        System.out.println("minutes=" + minutes);
        System.out.println("seconds=" + seconds);
    }
}
