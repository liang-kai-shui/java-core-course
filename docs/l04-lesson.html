先看一个反直觉结果：大盒子救不回先丢掉的小数

double answer = 7 / 2;看上去有double，为什么仍不是3.5？左边负责保存结果，右边已经按两个int先算出了3。每个中间表达式都有自己的类型与求值时机。

7(int) / 2(int) → 3(int) → 保存到double得到3.0
7.0(double) / 2 → 3.5(double) → 保存到double仍3.5

类比用窄量杯先量过、把细节舍掉，再倒进大杯：容量更大不能恢复已丢信息。边界是“窄/大”只是帮助认识信息损失，真实类型还涉及精度、整数回绕和转换规则，不能靠杯子大小替代判断。

学习段 必须看清哪一步 练习连接
除法与余数 运算时的类型、商和剩余量 平均数、秒数拆分

真假与短路 右边是否真的执行 除数0的保护条件

Math.sqrt是通过类使用的静态方法；本课main中的7/2是表达式，二者不是同一种语法。S01解释的“调用”读法仍适用，S03再讲怎样设计自己的静态方法。位运算和枚举放在明确的深化段，不挡住平均数这些基础任务。

1. 同样是除以 2，为什么有两个答案

要把 7 个整单位平均分两份，数学写 7÷2=3.5。程序中的 /还要看两侧数值的类型。

public class DivisionSteps {
    public static void main(String[] args) {
        System.out.println(7 / 2);
        System.out.println(7 / 2.0);
        double late = 7 / 2;
        double early = (double) 7 / 2;
        System.out.println(late);
        System.out.println(early);
    }
}

输出 3、3.5、3.0、3.5。先别背，沿执行过程看：

计算 先发生什么 交给输出或变量的值
7 / 2 两边 int，做整数除法 int 3
7 / 2.0 有 double，按 double 运算 double 3.5
double late = 7 / 2 先得到整数 3，再转换保存 double 3.0
(double) 7 / 2 先把 7 转为 double，再除 double 3.5

像先把分数小数部分剪掉，再放进大盒子，大盒子不能把剪掉的部分变回来。类比只帮助理解时机，真实规则是表达式先按运算类型求值，之后才做赋值转换。

整数除法向零截断，所以 −7/2 是 −3，不是向更小的整数取 −4。改成 −7，先预测四行再运行。

2. 余数不是百分比

%在这里计算除法剩下多少，例如 7%2=1。对于整数，可以用“商×除数＋余数＝被除数”核对。

把 3671 秒拆为时分秒：先取一小时 3600 秒的整份数，余下部分再取一分钟 60 秒的整份数。

public class SecondsWalk {
    public static void main(String[] args) {
        int total = 3671;
        int hours = total / 3600;
        int remaining = total % 3600;
        int minutes = remaining / 60;
        int seconds = remaining % 60;
        System.out.println("hours=" + hours);
        System.out.println("minutes=" + minutes);
        System.out.println("seconds=" + seconds);
    }
}
阶段 运算 得到什么
分出整小时 3671/3600 1
剩余秒数 3671%3600 71
分出整分钟 71/60 1
剩余秒数 71%60 11

先用 59、60、3600 预测，特别看“刚好整分钟”和“刚好整小时”。只测 3671 会错过临界条件。这里约定非负总秒数；不把这种拆分直接当作负时间格式化方案。

负数余数与被除数同号或为零，例如 −7%2 为 −1。余数运算也不是 Java 的“百分数类型”。

3. 类型转换要赶在信息丢失以前

类型转换是将值按另一种类型表示。(int)3.9中的 (int)要求转为 int，得到 3；这不是四舍五入。(int)-3.9得到 −3。

int 转 long 可以保留所有 int 值；double 转 int 可能丢小数。long 转 double 虽然范围可能够，仍可能丢整数精度。“能容纳更大数量级”与“每个整数都精确”是两回事。

public class MultiplicationWidth {
    public static void main(String[] args) {
        int count = 1_000_000;
        long late = count * count;
        long early = (long) count * count;
        System.out.println(late);
        System.out.println(early);
    }
}

正确目标是 1000000000000。第一种乘法的两个操作数都是 int，计算已溢出，后面的 long 只是保存了溢出后的结果；第二种先把一个操作数转为 long，使乘法采用 long。

预测：(long)(count*count)能救回结果吗？不能，括号把强制转换放在乘法之后。不要只检查等号左边写什么类型，要检查每一步运算发生时是什么类型。

算术运算符还包括 +、−、*；乘除余数比加减优先。2+3*4为 14，(2+3)*4为 20。括号应表达需要的计算，而不是碰到错误随意多套几层。

4. 更新变量时，值与动作分开记

total += value可先读作“取 total 加上 value，再写回 total”。对简单 int 相加，它与 total=total+value同样更新；遇到不同类型时，复合赋值还有转换规则，不能把这一等价解释扩展到所有表达式。

public class IncrementSteps {
    public static void main(String[] args) {
        int n = 4;
        int first = n++;
        int second = ++n;
        System.out.println("n=" + n);
        System.out.println("first=" + first);
        System.out.println("second=" + second);
    }
}
语句 开始 n 这一表达式提供什么值 最后 n 接收方
first=n++ 4 旧值 4 5 first=4
second=++n 5 新值 6 6 second=6

++叫自增，表示加一；后置提供旧值，前置提供新值，两种都改了变量。单独一行 n++;没有人接收旧值，但 n 仍增加。L08 循环的更新位置通常不使用这个表达式的返回值，因此两种简单整数写法效果相同。

--相应减一。先用独立语句，不把多个自增挤成炫技算式。Java 的求值有自己的规则，不能拿 C++ 的未定义行为结论直接套用。

补充观察：short s=1; s+=1;可以通过；s=s+1;的加法先得到 int，直接赋回 short 会编译失败。现在优先用 int 完成任务，不要求靠这条隐式转换省字。

5. 条件也是能计算的值

比较问两个值的关系，计算结果类型是 boolean：

写法 含义 例子
<、<= 小于、小于或等于 3<=3 是 true
>、>= 大于、大于或等于 2>3 是 false
== 是否相等 2==2 是 true
!= 是否不等 2!=2 是 false

=赋值、==比较，少一个字符会改变操作。Java 条件需要 boolean，不能把任意整数当真假。

逻辑运算把真假问题组合：&&是同时成立，||是至少一项成立，!把真假反转。

例如“年龄至少18并且不超过25”写成 age>=18 && age<=25。不能写 18<=age<=25，因为前半比较已经得到 boolean，不能继续拿这个真假值与 25 作数值大小比较。

6. 短路：结果已确定，就不执行右边

像检查两项入场条件：如果第一项已经不满足，“两项都满足”就不可能成立。类比的关键是有些后续动作根本没做，不仅仅是“做了但忽略结果”。

public class ShortCircuitWalk {
    public static void main(String[] args) {
        int divisor = 0;
        boolean result = divisor != 0 && 10 / divisor > 1;
        System.out.println(result);
    }
}

先算 divisor!=0，得到 false；&& 的整体已确定 false，右边除法不执行，所以正常输出 false。把 divisor 改 2，左边真，才计算 10/2>1，结果 true。

对 ||，左边为 true 时已经满足“至少一个”，右边不执行。!true是 false。

在副本把 && 改成 &，除数仍 0：两个 boolean 操作数都会求值，右边发生整数除零异常。这是预期运行失败实验，不能拿它要求正常输出 false。

后续会用这条规则先检查对象不为 null、下标合法，再访问内容；现在只用除法建立执行顺序。

7. 用本课知识完成平均数

先写中文：三个整数相加得到总分，再用浮点除法得到平均值。建 Average.java 时先只固定 80、80、81，不混入尚未学的键盘输入。

  1. 三个 int 分别保存成绩。
  2. int total 保存它们的和，本题范围不大。
  3. 写 double average=total/3.0;，确保除法本身是浮点运算。
  4. 先输出 total，再输出 average，定位计算在哪一步错。

若用 80、81、82，整数除法也刚好得到 81，容易遮住错误；改成总分不能被 3 整除的一组，才能区分算法。测试不是多跑几次，而是用能揭示不同情况的数据。

8. 先会查，不急着背的工具

Math是标准库的数学工具类：Math.sqrt(9.0)求平方根，Math.pow(2.0,3.0)求 2 的 3 次方。点表示访问工具提供的方法，括号内是参数。Java 的 ^不是乘方，是按位异或；平方也可直接用 x*x。

条件表达式写作 条件 ? 真时的值 : 假时的值，例如 score>=60 ? "pass" : "retry"。它选一个值，可以交给输出；L07 再将它与选择执行一段代码区分。

位运算针对整数的二进制位，常见符号为 &、|、^、~、<<、>>、>>>。枚举为有限选项命名。这两部分先知道解决什么问题，作为教材深化，不增加本课必做要求。

浮点观察：输出 0.1+0.2，并比较它与 0.3 的 == 结果。许多十进制小数不能被二进制浮点精确表示，微小误差不等于计算随机。到了 L09 再学按明确十进制规则处理数值。

本课过关：解释先计算后赋值、转换时机、余数、自增及短路；独立完成秒数拆分与不会先丢小数的平均数。关键规则依据可按需查 Java 表达式规范，阅读规范不作为入门前提。

深化：转换图背后的运算规则

进行本课普通二元数值运算前，要先对齐操作数类型：有double就转double；否则有float就转float；否则有long就转long；否则按int。这也解释byte与short相加通常得到int，不能仅因两个值都很小就认为结果类型自动仍是short。

范围扩大仍可能精度变小：int到float、long到float、long到double都可能丢有效信息。用int exact=123456789; float approximate=exact;，打印两者观察差异；教材图3-1中的实线与虚线正是在区分能转换与是否保真。

强转不是四舍五入。想在限定的小数值例子中取最近整数，可调用Math.round；double版本返回long，再转int还要另判断目标范围。窄整数强转也可能丢高位，例如(byte)300得到44，不能用强转替代输入范围检查。

Math除sqrt与pow外，还提供Math.PI、Math.E、sin/cos等方法。静态方法先按“类提供的操作”使用；书中静态导入可以省Math前缀，本课保留前缀更便于辨认，S03会解释它为什么不需要先创建一个Math对象。

时钟向前或向后调整适合展示Math.floorMod：从位置1后退3格，(1-3)%12为−2，Math.floorMod(1-3,12)为10。这里除数正12，因此结果落在0–11；不要把这个范围承诺扩展到负除数。

深化：位运算、枚举与版本边界

位运算先有一个可手算的例子

5的低四位是0101，3是0011。按位与&逐位都为1才得1，所以5&3为0001，也就是1；按位或|得到0111即7；异或^在不同位上得1，得到0110即6。这与boolean短路运算的含义、执行方式要分开。

左移1<<3得到8；>>右移补符号位，>>>右移补0。int的移位距离只取低5位，因此1<<35与1<<3相同；long距离取低6位。先会读小例子与区分符号，掩码算法不作为必做。

括号、结合方式与求值顺序不是同一件事

a&&b||c按(a&&b)||c分组，复杂规则主动写括号。结合方式回答“语法怎样分组”，实际执行还要遵循Java求值及短路规则。Java没有C++那样的一般逗号运算符；for某些位置的逗号列表是另一语法。

枚举先解决“只能从几种名字选一个”

枚举定义有限个命名选项。衣服尺码若直接用整数，很容易装进含义不明的99；枚举让变量明确只属于该组选项，仍需认识null等边界。

public class SizeChoice {
    enum Size { SMALL, MEDIUM, LARGE }
    public static void main(String[] args) {
        Size selected = Size.MEDIUM;
        System.out.println(selected);
    }
}

enum声明放在外层类中、main之外；Size是新类型，Size.MEDIUM是其中一项。输出MEDIUM。把赋值改成整数2会编译失败；用枚举不是请编译器猜“2代表中号”。第5章再深入枚举类，这次只练这种基本使用，不新增必交题。

版本补充：书本p38–39 / PDF p56–57的strictfp讨论属于Java 8时期的浮点执行背景。本机JDK21采用Java 17起的始终严格浮点语义，不能把旧版默认/严格差别当作本机实验结论；见Oracle迁移说明。这不要求改本课普通算术程序。

独立迁移：先决定每一步的类型，最后才决定显示

给平均值画一条处理线：三个int→整数总和→除法→double结果→输出文字。转换放在除法前，才能保留小数；在结果已经成80后再转double只能得80.0。格式化到两位也是最后一步，不会倒流修复运算。

迁移检查：7/2、(double)(7/2)、((double)7)/2逐个标出“除法发生时两边类型”。再用80、80、81代替恰好整除的一组，观察它能暴露哪种错法。秒数拆分则用还原等式hours3600+minutes60+seconds==total，额外核对分、秒均在0到59。
