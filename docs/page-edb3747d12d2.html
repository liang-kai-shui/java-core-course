P1 指定输出样例

输入（换行或空格分隔均可）：

4
59 60 90 100

输出：

original=[59, 60, 90, 100]
sum=309
average=77.25
max=100
min=59
passed=3
sorted=[59, 60, 90, 100]

另外用3 / 90 0 60验证排序副本确实不改变original（斜杠在这里代表换行，不是实际输入）。n为0或越界时只输出对应的一行；不要求继续读取成绩。平均值固定US小数点及两位小数。格式与字段名是本题明确要求，不是通用代码风格要求。
