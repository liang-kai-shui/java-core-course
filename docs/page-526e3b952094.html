与正文不同的处理须说明原因

  • 第2章旧JDK安装界面改为本机项目配置；IDE从Eclipse适配到本项目VS Code任务。普通应用的编译启动规则保持对应，未改全局PATH。
  • applet与旧浏览器操作保留历史意义，不列为当前实践要求；GUI仅认识运行形式，细写窗口按原书后续章节推进。
  • 本地书本p34 / PDF p52将U+00A0说明为换行有误，讲义按正确的LF U+000A说明，并区分Unicode转义的早期处理。
  • 书本p38–39 / PDF p56–57的strictfp讨论属于旧版本背景；本机JDK21的执行语义另注明，不把它说成Java8虚拟机实测。
  • 书本p84–85 / PDF p102–103部分Arrays API的type[]范围概括过宽；sort、binarySearch不能据此推断适用于boolean[]。实际方法类型应另核验。
