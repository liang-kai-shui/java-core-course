Q1：b=a共享同一数组；copyOf对int数组复制元素形成独立数组；数组.length是字段，String.length()是方法。

E1：original=[9, 1, 2]；sorted copy=[1, 2, 9]；after foreach=[9, 1, 2]；index of 2=1。增强for的int变量是每次取出的值副本。E2：参考RaggedSum，对每行使用自己的length，结果15。P1：参考ScoreStats.java。先处理n非法和0，再访问首元素；排序必须用副本。P2：n=-1/101→invalid count；0→no data；单个0→sum0/average0.00/max0/min0/passed0；单个100→sum100/average100.00/max100/min100/passed1。其余样例见题目与验证报告，批改仍需运行学生原提交。

RaggedSum.java
public class RaggedSum {
    public static void main(String[] args) {
        int[][] values = {{1, 2}, {3, 4, 5}, {}};
        int sum = 0;
        for (int row = 0; row < values.length; row++) {
            for (int column = 0; column < values[row].length; column++) {
                sum += values[row][column];
            }
        }
        System.out.println("sum=" + sum);
    }
}
ScoreStats.java
import java.util.Arrays;
import java.util.Locale;
import java.util.Scanner;
public class ScoreStats {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        if (n < 0 || n > 100) {
            System.out.println("invalid count");
            return;
        }
        if (n == 0) {
            System.out.println("no data");
            return;
        }
        int[] scores = new int[n];
        for (int i = 0; i < n; i++) {
            scores[i] = in.nextInt();
        }
        int sum = 0;
        int maximum = scores[0];
        int minimum = scores[0];
        int passed = 0;
        for (int score : scores) {
            sum += score;
            if (score > maximum) { maximum = score; }
            if (score < minimum) { minimum = score; }
            if (score >= 60) { passed++; }
        }
        int[] sorted = Arrays.copyOf(scores, scores.length);
        Arrays.sort(sorted);
        System.out.println("original=" + Arrays.toString(scores));
        System.out.println("sum=" + sum);
        System.out.printf(Locale.US, "average=%.2f%n", sum / (double) n);
        System.out.println("max=" + maximum);
        System.out.println("min=" + minimum);
        System.out.println("passed=" + passed);
        System.out.println("sorted=" + Arrays.toString(sorted));
    }
}
