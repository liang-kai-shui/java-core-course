先弄懂层级，再逐步扩大程序

讲义承担完整基础教学，PDF用于学会以后的深化阅读。按实际作答调整每次学习量，不用固定周数催进度；材料准备、教师实测与学生通过分别记录。

建议顺序：L01 → L02 → S01 → L03 → L04 → S02 → L05–L10 → S03–S06。

  • S01在第一次手动运行后解释类与main，不再让整套结构悬空到第4章。
  • S02接在类型与赋值之后，用对象引用解释String、Scanner和数组前会遇到的new。
  • S03–S06把已经学过的数据与流程组织成类、多文件、包、归档、依赖和资源。
  • S课是基于教材正文的提前桥接，主线仍按书中章节深化；S05–S06只使用第13章13.1的结构基础，不代表全章部署内容都已学习。
