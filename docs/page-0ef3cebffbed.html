阅读取舍

L01完整理解Java是什么，历史年代不要求背诵。L02以已安装的JDK21和命令行为准；2.5 applet只作历史阅读。第3章的位运算、Unicode码点、大数值和不规则数组均有明确学习层级，选读不能冒充完全没提过。

后续仍按原书顺序经过Swing；GUI可以按兴趣调整深度。第13章的applet和Java Web Start只作历史了解。finalize和Thread.stop/suspend作为旧机制辨析，不要求照抄为实践方案。更新依据见环境说明。

过关原则

每课必做题齐全、核心概念正确、题目指定验证有依据才通过。选做、风格优化或尚未讲过的高级写法不作为卡关条件。前课通过状态不因开新课重置。当前实际进度只记在进度追踪.md。
