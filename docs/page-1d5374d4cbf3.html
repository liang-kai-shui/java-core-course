L06 参考答案与解析

对应本课练习。先自己尝试，再看为什么。题目为课程原创；允许其他正确解法，参考程序也需要接受核对。以下是材料解析，不是对学生作答的批改结论。

Q1：读取位置要接着走

next取空白分隔片段，nextInt把下一片段解析为整数；nextLine取当前位置到本行末的剩余正文并跨过行分隔符。

操作 输入18后回车，再输入Li Ming的情形
nextInt 得到18，位置仍在数字所在行末
第一次nextLine 剩余正文为空，得到空串
再一次nextLine 读取下一行Li Ming

“消费数字那一行的剩余内容”比“永远吃一个回车”准确：若同一行还有姓名，也会被读走。

E1：姓名先读，数字后读

参考Bill.java。先nextLine保存完整姓名，再nextDouble和nextInt；price*count得到总额，printf的%.2f按两位小数显示，Locale.US明确点号。

Li Ming、12.5、3得到name=Li Ming与total=37.50。数量0得到0.00；0.1乘3显示0.30。若姓名只有Li，先查是否误用next。

E2：数字后再读下一行

参考AgeName.java。nextInt之后先消耗该行剩余，再读取下一行姓名，18与Li Ming输出Li Ming:18。

两次nextLine职责不同，不能无解释地把它们合并或删除。若题目改为同一行输入，需重新设计读取协议。

E3：观察磁盘文件，而不只看终端

原例应打印你好，Java！，指定路径文件也存放相同文字与行结束符。相对路径从运行进程工作目录算起，编码双方使用UTF-8。

需记录真实目标位置和打开结果；仅写“运行成功”不足以证明找到了文件。文件操作覆盖同名目标，只用新实验文件名。

Q2：显示舍入不是改变原值

printf选择显示字符和位数，不使底层double神奇变成精确十进制0.3。可以同时输出原计算结果与格式化结果，区别“值的近似表示”与“显示效果”。

AgeName.java
import java.util.Scanner;
public class AgeName {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int age = in.nextInt();
        in.nextLine();
        String name = in.nextLine();
        System.out.println(name + ":" + age);
    }
}
Bill.java
import java.util.Locale;
import java.util.Scanner;
public class Bill {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in).useLocale(Locale.US);
        String name = in.nextLine();
        double price = in.nextDouble();
        int count = in.nextInt();
        System.out.println("name=" + name);
        System.out.printf(Locale.US, "total=%.2f%n", price * count);
    }
}
