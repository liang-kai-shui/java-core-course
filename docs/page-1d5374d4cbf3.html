L06 参考答案 · 先独立作答

本文件是课程原创参考，允许其他正确解法。代码与参考答案通过验证不等于学生已通过。

Q1：next按空白读片段，nextLine读当前行剩余内容并跨过分隔符，nextInt解析整数而通常留下后续分隔符；下一次nextLine先取到数字所在行的余下内容。Q2：格式化只是显示舍入，不证明原浮点值是精确0.3。

E1：参考Bill；Li Ming、12.5、3→name=Li Ming / total=37.50；数量0→0.00；0.1×3显示0.30。E2：参考AgeName；在年龄后消耗该行余下内容，再读下一行。E3：参考code/FileUtf8Demo；用新实验路径，程序应打印你好，Java！且磁盘文件保存同样文字（含行结束符）。相对路径以进程工作目录为起点，写入与读取均指定UTF-8。

本目录中的.java文件可分别独立运行；部分实验直接对照上级code或error_lab。原始题目和指定输入输出优先于参考实现，发现矛盾应核实后修正。

AgeName.java
import java.util.Scanner;
public class AgeName {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int age = in.nextInt();
        in.nextLine();
        String name = in.nextLine();
        System.out.println(name + ":" + age);
    }
}
Bill.java
import java.util.Locale;
import java.util.Scanner;
public class Bill {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in).useLocale(Locale.US);
        String name = in.nextLine();
        double price = in.nextDouble();
        int count = in.nextInt();
        System.out.println("name=" + name);
        System.out.printf(Locale.US, "total=%.2f%n", price * count);
    }
}
