先找到数据归谁，再填写变量

在S01你已经把“文件→类→方法→语句”分开。本课增加一项：main这次执行中保存的局部数据。先用计数记录理解变量，再认识不同数据类型，不把所有声明都误称为“类的属性”。

CountNotebook.java（文件）
└─ CountNotebook（类）
   └─ main（方法）
      ├─ int count = 3;   ← 本次调用使用的局部变量
      ├─ 输出count
      └─ 更新count

变量可以类比为表格中有名称、类型规则和当前值的一栏。“人数”栏填3，下一步改4；栏名count没有跟着变。边界：后面引用变量的格子里放的是引用，不是把整个对象塞在这里；不能用整数格子的图解释所有变量。

学习段 要回答的问题 自己动手
程序与注释 哪些是执行步骤，哪些只给人看 改输出顺序，再改注释，比较现象
类型与字面量 这项数据允许什么值和操作 姓名、年龄、身高、是否报名分别选类型
赋值与final 变的是值、名字，还是约束 画两格追踪复制，再做一次赋值限制实验

本课的类常量只是对比位置；实例字段将在S02、S03用实际对象讲。先圈大括号，再说一个名字属于main还是类，避免记住public却放错声明位置。

1. 程序外壳与执行（教材3.1）

假设我们要打印人数。先看完整程序，再追踪一条数据：

public class CountNotebook {
    public static void main(String[] args) {
        int count = 3;
        System.out.println(count);
        count = count + 1;
        System.out.println(count);
    }
}

输出依次是 3、4。外层 class 命名 CountNotebook；里面的 main 是启动方法；main 花括号里是本次按顺序执行的四条语句。

语句是程序中的一步操作，例如建立变量、赋值、调用输出。代码块用一对花括号把若干语句围在一起，像文件夹把内容分组。但块不等于磁盘文件夹，这只是帮助辨认层次的类比。

类 CountNotebook
└─ 方法 main
   ├─ 创建 count，放入初值 3
   ├─ 输出 count
   ├─ 更新 count
   └─ 再次输出 count

启动模板逐项先有一个能用的认识：public 表示公开可访问；static 让这次启动无需先创建 CountNotebook 对象；void 表示方法不向调用方返回一个结果值；main 是入口名字；String[] args 接收启动文本。S01已经逐项解释入口及一次调用；本课继续把注意力放在main的局部数据。S02与S03再用对象说明字段、构造器与实例方法，不把所有声明都混成同一种外壳。

输出数字与输出名字

System.out.println(age);        读取变量 age 的值
System.out.println("age");      显示 a、g、e 三个字母
System.out.println("age=" + age);  标签后接数值

引号外是代码，需要按名字找到变量或计算；引号内是正文。中文输出没有问题，变量命名阶段先用有意义的英文如 studentCount，避免把多个变量叫 a1、a2 却记不清用途。

变量名区分大小写，不能用 class、int 这样的语言关键字。普通变量用小驼峰：第一个词小写，之后每个词首字母大写。命名约定帮助人读，不能替代 Java 的合法命名规则。

2. 注释（教材3.2）

注释是给阅读代码的人看的说明，不作为普通语句执行。像工作单旁的便笺，不能靠写便笺改变实际操作。

把CountNotebook中的初始化一行改成下列片段，其他外壳不变：

// 人数从当前已报名的三人开始
int count = 3;
/* 下一步只增加一名，不是重新读取名单 */

重新运行，数字不因注释文字而改变。//到这一行结束；/* ... */可以跨行；/** ... */是文档注释形式，后续用于生成类与方法说明。

块注释不能嵌套：内层的第一个结束标记就可能提前结束整段。想暂时停用包含块注释的多行，可逐行加//。但引号中的"//"是文本，不会注释掉后面源码。

教材书本p34 / PDF p52还提醒Unicode转义处理发生得很早，甚至可能影响注释。此页将U+00A0说明为换行不准确；换行LF是U+000A。不要照抄这处错字去制造实验。普通注释无需使用这类转义，规则依据见Java词法规范。

3. 数据类型（教材3.3）

“人数”“单价”“是否报名”需要不同的数据规则。类型规定可能保存哪些值，也决定哪些操作允许。像登记表的整数栏、金额近似值栏、是/否栏；标签帮助检查填错数据，却不能替你检查“人数为负”这样的业务规则。

类型 先知道的用途 本阶段选择
byte、short、int、long 不同范围的整数 普通计数先用 int，确需更大用 long
float、double 浮点数，能表示带小数的近似数值 普通教学计算先用 double
char 一个 UTF-16 代码单元 先处理 'A'、'中' 这类例子
boolean 真假判断 只有 true、false，不用 0/1 自动替代

这八种叫基本类型。String 表示文本，是引用类型，不属于这八种。

整数范围：byte 为 −128 到 127，short 为 −32768 到 32767，int 为 −2147483648 到 2147483647，long 为 −9223372036854775808 到 9223372036854775807。Java 这些类型的数值范围有规定，不需因为电脑位数不同就猜 int 改成另一种范围。

不用第一遍背完十几位上限，先知道“够不够”需要判断。程序里可用 Integer.MAX_VALUE 等现成常量查看。boolean 的语言值只有真假，这不等于可以据此断言每个 boolean 在任意内存布局中必占一个字节。

写在源码里的值

字面量就是直接写出来的值，如 18、1.75、true、'A'、"Java"。它不是变量名。

public class ProfileWalk {
    public static void main(String[] args) {
        String nickname = "Java learner";
        int age = 18;
        double height = 1.75;
        boolean started = true;
        char group = 'A';
        long population = 3_000_000_000L;
        System.out.println("name=" + nickname);
        System.out.println("age=" + age);
        System.out.println("height=" + height);
        System.out.println("started=" + started);
        System.out.println("group=" + group);
        System.out.println("population=" + population);
    }
}

单引号 'A' 是 char 写法，双引号 "A" 是 String 写法。3_000_000_000 中的下划线帮助人分组，不是小数点；L 指明 long 整数字面量，建议大写避免与数字 1 混淆。

普通小数字面量如 1.75 默认是 double。若要 float，可写 1.75f。更大的范围、更多有效数字不等于精确表示所有小数，第 L04 课会用 0.1 做实验。

先预测再修改：将 age 改为 19，只应影响 age 那行；将引号内 "age=" 改为 "年龄="，只改标签，不改 age 的数值。引号内的文字不会自动关联同名变量。

范围与Unicode边界

public class TypeEdges {
    public static void main(String[] args) {
        int maximum = Integer.MAX_VALUE;
        System.out.println(maximum);
        System.out.println(maximum + 1);
        System.out.println("中".length());
        System.out.println("😀".length());
    }
}

输出：

2147483647
-2147483648
1
2

整数计算超出 int 范围，不会自动升级成 long，也不会总以异常提醒；这里发生回绕。像计数器转过最大刻度，但真实规则是固定宽度的整数运算，不是所有数字类型都用同一行为。

Unicode为字符分配编号，UTF-16 代码单元是 Java char 和 String 操作中的一种计量单位；有的字符要用两个单元。可以把“一个字用两格记录”作为类比，但两格不是两个可独立显示的完整字符。

所以 char 不能存放任意一个完整 emoji，String.length() 也不能一概叫屏幕字数。这里能解释 1、2 的差别即可；码点与更复杂的文字组合到字符串课再分层处理。

进制、浮点特殊值与转义

十进制9、二进制0b1001、十六进制0x9可以表示相同整数；前缀0开头的010是八进制8，不能把前导0当作纯排版。下划线帮助阅读，不改变数值。本课普通计数用十进制，其他进制先会辨认。

float约有6–7位十进制有效数字，double约15–16位；有效数字不等于小数点后固定多少位。整数除零会异常，但浮点数1.0/0.0得到正无穷，0.0/0.0得到NaN。NaN表示不是普通数值，检测用Double.isNaN，不用与Double.NaN作==判断。可在TypeEdges中逐条加入输出，观察这三个结果分别是Infinity、NaN、true。

转义用特别的写法表示难以直接写进引号的字符。\n是换行，\t是制表，\"表示正文双引号，\\表示正文反斜杠。例如在main内输出"A\nB"会显示两行；输出Windows路径时源码中的一个反斜杠常需写成两个。这里说的是Java字符串的写法，与PowerShell路径字符串的规则不同。

4. 变量与初始化（教材3.4）

如果程序只写 println(3)，人数变化后就要到每个位置改数字。变量让一项运行数据有一个可以反复使用的名字。像记录本上一栏叫“人数”，本轮记 3，后来改成 4。

int count = 3;可以拆成：

部分 负责什么
int 规定这项数据是一定范围的整数
count 自己取的变量名
= 3 建立时给初始值
; 结束语句

声明让这个名字与类型进入程序；初始化是在建立变量时给它值。之后 count = 4;是再次赋值，没有重新声明一个 count。

名字像标签，基本类型变量的值可画在格子里。以后学到引用时，格子里保存的是引用，不能把所有变量一概画成“直接装着整个对象”。本节只跟踪整数。

赋值是一次写回

数学的 x=x+1很奇怪，程序的 count=count+1却很常用：先取右侧 count 的旧值，加 1，再把结果放回左侧。

当前语句 执行前 count 右侧计算或动作 执行后 count
int count = 3 尚未建立 给初值 3 3
println(count) 3 读出并显示 3
count = count + 1 3 3+1 得 4，再写回 4
println(count) 4 读出并显示 4

表达式是会计算出一个值的组合，如 count+1。只计算不等于已经写回。

在 main 中再试下面的片段，替换原来的四条语句：

int first = 3;
int second = first;
first = 9;
System.out.println(first);
System.out.println(second);

应是 9、3。第二条把当时的值 3 复制给 second，不是建立“永远跟随 first”的关系。请画两个格子，先填 3，再只把 first 改成 9。

随堂修改：在两次输出之间加入 second=first;，预测第二个结果。想更新第二个变量，必须有实际赋值动作。

初始化、final与作用域

局部变量是本例在方法内部声明的变量。使用它之前，编译器必须能确定已经赋值。

下面是预期编译失败片段，只在副本测试：

int count;
System.out.println(count); // 此时没有可读取的已赋值结果

int count;本身可以声明变量；错误出在尚未赋值就读取。不要用“电脑会自动给零”解释这里。以后数组元素有默认值，那是另一条规则。

final 变量只允许赋值一次。对于这里的基本类型常量，可用来保存不会变的含义：

public class WeekPlan {
    public static void main(String[] args) {
        final int DAYS_PER_WEEK = 7;
        int weeks = 2;
        int days = weeks * DAYS_PER_WEEK;
        System.out.println(days);
    }
}

输出 14。把 weeks 改 3，应得 21。再在副本尝试 DAYS_PER_WEEK=8;，应编译失败。final 不是“所有涉及它的结果都固定”，weeks 仍可变化；引用上的 final 以后也不等于对象完全不可变。

作用域是一个名字可以被使用的代码区域。main 内 count 不能拿到另一个完全无关的方法里随便使用。现在先画花括号范围，L07 会通过代码块实验加深；不要把“名字不可用”与“某块内存具体何时被回收”混为一谈。

局部常量与类常量

当前WeekPlan把DAYS_PER_WEEK放在main内，是局部final变量。若希望多个方法都能使用同一个类常量，可把声明移到类内、main外，并写public static final int DAYS_PER_WEEK=7;。

public class WeekPlan {
    public static final int DAYS_PER_WEEK = 7; // 类内，方法外
    public static void main(String[] args) {
        // 原来这里的局部DAYS_PER_WEEK声明删去，其余计算保留
    }
}

这是位置对照片段，不是替换全部程序的完整文件。static在这里先读作属于类的成员，public使其他类能按类名访问；S03会按每份状态属于谁解释这些成员规则。不能把C++的const写法搬来，Java本处使用final。

5. 自己开始写Profile

原练习 E1 要求个人信息。先不看上面的完整程序，按四步来：

  1. 在纸上列“昵称、年龄、身高、是否开始、每周天数”。
  2. 为每项选类型：文本、整数、近似小数、真假、固定整数。
  3. 先只写昵称并运行，再逐项增加，不要一次抄完才找报错。
  4. 按“字段=值”核对每行。修改一个值，确认对应行变化。

E2 的两个失败实验分别测“读取之前有没有赋值”和“能否第二次赋值”；不要把它们混为同一问题。E3 是观察边界，不要求背 Unicode 全部编码标准。

本课过关：能追踪赋值、选合适的类型、独立建立与输出变量、解释初始化和 final，并准确区分文本内容与变量名。

独立迁移：同一个名字在不同语法位置，为什么不是同一回事

把Profile中的年龄分成三张卡：int是类型规则，age是变量名，18是当下的值。输出age读值，输出"age"只显示字母。先改变18→19，标签不应变化；再改输出标签，数值不应变化。两步分开，就能知道你是在改程序数据还是正文。

对赋值做一次纸上迁移：first=3，second=first，first=9，second=first。每一步单独画两个格子，第二步不是建立永久联动，第四步才更新second。最后解释局部变量声明、首次赋值、再次赋值的不同；final限制再次赋值，不等于表达式结果从此全都不变。
