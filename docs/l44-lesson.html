学完要能做什么

能把同一Action接到菜单和工具栏；区分助记键、加速键与焦点；按行列、权重、填充逐项组织GridBag布局，并说明GroupLayout和自定义布局的使用边界。

菜单里和工具栏上都有“记录”，要写两份业务代码吗

想象办公室的同一台打印机有墙上按钮和桌面按钮。两个入口应调用同一项工作，停用打印时两个入口都应停用。Action像共同的操作说明与执行对象，JMenuItem、JButton是不同入口；类比边界是Action不是后台线程，也不会自动保存文件，真正工作仍是actionPerformed中的代码。

JMenuBar装JMenu，JMenu再装JMenuItem或子菜单；菜单栏通过frame.setJMenuBar安装，不当作中心正文add进去。JToolBar可装按钮，宜放BorderLayout.NORTH；可停靠工具栏属于界面入口，不等于后台业务系统。本课的“记录”只更新内存计数，标题和状态都明确说明这一点，不会保存到磁盘。

import java.awt.BorderLayout;
import java.awt.EventQueue;
import java.awt.event.ActionEvent;
import javax.swing.*;
public class MenuWorkbench {
    static class Work {
        final JPanel panel = new JPanel(new BorderLayout());
        final JLabel status = new JLabel("0");
        int count;
        final Action record = new AbstractAction("记录（内存）") {
            private static final long serialVersionUID = 1L;
            public void actionPerformed(ActionEvent e) { status.setText(String.valueOf(++count)); }
        };
        final JMenuBar bar = new JMenuBar();
        final JMenuItem item = new JMenuItem(record);
        final JButton button = new JButton(record);
        final JCheckBoxMenuItem readOnly = new JCheckBoxMenuItem("只读");
        Work() {
            record.putValue(Action.ACCELERATOR_KEY, KeyStroke.getKeyStroke("control S"));
            item.setAccelerator((KeyStroke) record.getValue(Action.ACCELERATOR_KEY));
            JMenu file = new JMenu("操作"); file.setMnemonic('O');
            file.add(item); file.addSeparator(); file.add(readOnly); bar.add(file);
            JToolBar tools = new JToolBar(); tools.setFloatable(false); tools.add(button);
            readOnly.addActionListener(e -> record.setEnabled(!readOnly.isSelected()));
            panel.add(tools, BorderLayout.NORTH); panel.add(status, BorderLayout.CENTER);
        }
    }
    public static void main(String[] args) throws Exception {
        if (args.length > 0 && args[0].equals("--check")) EventQueue.invokeAndWait(() -> {
            Work w = new Work(); w.item.doClick(0); w.button.doClick(0); w.readOnly.doClick(0);
            System.out.println(w.status.getText()); System.out.println(w.item.isEnabled() + ":" + w.button.isEnabled());
        }); else EventQueue.invokeLater(() -> {
            Work w = new Work(); JFrame f = new JFrame("内存计数工作台"); f.setJMenuBar(w.bar);
            f.add(w.panel); f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); f.setSize(420, 180); f.setLocationByPlatform(true); f.setVisible(true);
        });
    }
}

默认运行打开窗口，先点菜单记录，再点工具栏记录，计数连续到2；勾只读以后，两处入口都灰掉。--check只创建组件并调用入口，输出2、false:false；它验证共享动作和启用状态，真实菜单展开、快捷键和窗口缩放还要在窗口里操作。

new AbstractAction("记录（内存）") { ... }创建匿名子类实例；花括号里的actionPerformed实现操作，不是当场执行。putValue(Action.ACCELERATOR_KEY, KeyStroke.getKeyStroke("control S"))把快捷键描述放入动作属性；JMenuItem会安装相应加速键，普通工具栏按钮不会仅因这个属性自动获得同样键盘绑定。Ctrl是本课Windows的选择，不承诺所有平台都采用同一按键。

new JMenuItem(record)和new JButton(record)分别把同一个对象交给两个视图；没有new两次Action。setEnabled是共享动作状态，视图监听它而更新。勾选只读时读取的是checkbox的选中状态，不用“每收到一次事件就反转”，避免程序设置状态与业务状态分离。

构建 0 true/true 0
菜单触发 1 true/true 1
工具栏触发 2 true/true 2
勾只读 2 false/false 2

只改一处：把record.setEnabled(!readOnly.isSelected())中的!去掉，先预测勾选前后是否符合“只读”含义，再运行。独立任务：另建清零Action，复用到菜单和工具栏；清零不应新建整个窗口，也不应把记录入口永久禁用。

助记键、快捷键和焦点不是一件事

助记键mnemonic用于键盘定位菜单，如Windows下Alt配合指定字母；加速键accelerator可在菜单没展开时直接触发该项；焦点是当前接收键盘输入的组件。文本框取得焦点不等于其他所有窗口级绑定失效，绑定条件和组件类型也起作用。中文标签可以另设拉丁助记键，不把字符串中碰巧出现字母当已安装快捷键。

JPopupMenu是弹出菜单；给组件setComponentPopupMenu后由Swing按平台触发习惯显示。若自己处理鼠标，两种按下/释放阶段都需检查isPopupTrigger，别固定右键按下。选择菜单项可用JCheckBoxMenuItem；互斥的JRadioButtonMenuItem同样需要ButtonGroup。分隔线只是视觉分组，不是可选业务项。

为什么“给输入框加宽”改了半天都不动

布局像摆桌子：网格位置决定坐哪里，跨格决定占几席，权重决定多出来的地方分给谁，fill决定分到以后身体是否伸展，anchor决定不伸展时靠哪里。类比边界是组件尺寸由首选/最小尺寸、容器当前尺寸和同列约束一起计算，不是一张绝对像素表。

GridBagConstraints里gridx是列、gridy是行；gridwidth跨列、gridheight跨行。weightx/weighty分配额外空间，fill有NONE/HORIZONTAL/VERTICAL/BOTH；anchor负责剩余格内对齐；insets是约束对象的外边距。weightx为0不能简单解释成“这个组件永远不变宽”：同列别的组件可能使该列获得额外宽度，最终是否填满仍看fill。

每次放组件重新new一份约束最容易排错，防止上一项的跨列或权重偷偷遗留。默认gridx/gridy是RELATIVE，不是0；讲义用显式坐标减少这种隐式状态。教材书本p521–528 / PDF p539–546的行列、insets所属类与默认坐标请按这些实际API规则理解。

GridBag：每放一个组件，都说明它的格子

import java.awt.*;
import javax.swing.*;
public class GridBagRows {
    static GridBagConstraints at(int x, int y) {
        GridBagConstraints c = new GridBagConstraints(); c.gridx = x; c.gridy = y;
        c.insets = new Insets(4, 4, 4, 4); c.anchor = GridBagConstraints.EAST; return c;
    }
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JPanel form = new JPanel(new GridBagLayout()); JTextField name = new JTextField(10), target = new JTextField(10);
            form.add(new JLabel("课程"), at(0, 0)); form.add(new JLabel("目标"), at(0, 1));
            GridBagConstraints a = at(1, 0); a.weightx = 1; a.fill = GridBagConstraints.HORIZONTAL; form.add(name, a);
            GridBagConstraints b = at(1, 1); b.weightx = 1; b.fill = GridBagConstraints.HORIZONTAL; form.add(target, b);
            GridBagConstraints c = at(0, 2); c.gridwidth = 2; form.add(new JButton("提交"), c);
            form.setSize(300, 160); form.doLayout(); int before = name.getWidth();
            form.setSize(500, 160); form.doLayout(); System.out.println("grows=" + (name.getWidth() > before));
        });
    }
}

程序在EDT里只构造与布局组件，不打开窗口，输出grows=true。这验证分配关系，不证明文字在所有系统缩放下都足够。label在(0,0)/(0,1)，输入在(1,0)/(1,1)，button在(0,2)跨两列。form.setSize是给离屏容器分配一次实际空间；doLayout执行布局，不是让用户拖动窗口。

约束 标签 输入框 提交
weightx 0 1 0
fill NONE HORIZONTAL NONE
gridwidth 1 1 2

只改输入框fill为NONE，宽面板仍能分到大格子，但组件不会用满；将返回的boolean打印改成两次数值，记录差异。独立任务：加第三行“目标分钟”，确认提交移至y=3而不是和新行重叠。

GroupLayout：一个组件要同时出现在两个轴的分组里

GridBag按格子描述，GroupLayout按两个轴分别描述。水平方向是“标签列在前，输入列在后”的顺序组，每列内部是并行组；垂直方向是“两行依次”的顺序组，每行内部按BASELINE并行。像分别给座位画横坐标和纵坐标，两个都填齐才能定位；类比边界是组还能决定伸缩和间隔，不只是坐标名单。

import java.awt.EventQueue;
import javax.swing.*;
public class GroupLayoutRows {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JPanel panel = new JPanel(); GroupLayout g = new GroupLayout(panel); panel.setLayout(g);
            JLabel first = new JLabel("课程"), second = new JLabel("备注");
            JTextField a = new JTextField(12), b = new JTextField(12);
            g.setAutoCreateGaps(true); g.setAutoCreateContainerGaps(true);
            g.setHorizontalGroup(g.createSequentialGroup()
                .addGroup(g.createParallelGroup().addComponent(first).addComponent(second))
                .addGroup(g.createParallelGroup().addComponent(a).addComponent(b)));
            g.setVerticalGroup(g.createSequentialGroup()
                .addGroup(g.createParallelGroup(GroupLayout.Alignment.BASELINE).addComponent(first).addComponent(a))
                .addGroup(g.createParallelGroup(GroupLayout.Alignment.BASELINE).addComponent(second).addComponent(b)));
            panel.setSize(360, 140); panel.doLayout();
            System.out.println("sameX=" + (a.getX() == b.getX())); System.out.println("rows=" + (a.getY() < b.getY()));
        });
    }
}

输出sameX=true与rows=true。每个字段都要在setHorizontalGroup和setVerticalGroup各出现一次；遗漏一轴会在布局阶段报错。setAutoCreateGaps添加组件间推荐间距，containerGaps加外边距，不必猜所有像素。只改垂直第二行顺序放到前面，预测行顺序变化，水平两列不变。独立任务：加第三行，先画两棵组树再写代码。图形设计器可生成这些约束，理解约束仍是排错前提；不要求额外安装某个IDE才能完成本课。

弹出菜单：选择状态属于模型，分组不负责显示

import java.awt.Color;
import java.awt.EventQueue;
import javax.swing.*;
public class PopupChoices {
    static class View {
        final JPanel panel = new JPanel(); final JPopupMenu menu = new JPopupMenu();
        final JCheckBoxMenuItem mark = new JCheckBoxMenuItem("标记");
        final JRadioButtonMenuItem shortMode = new JRadioButtonMenuItem("简洁", true), longMode = new JRadioButtonMenuItem("详细");
        View() {
            ButtonGroup group = new ButtonGroup(); group.add(shortMode); group.add(longMode);
            menu.add(mark); menu.addSeparator(); menu.add(shortMode); menu.add(longMode);
            panel.setBackground(Color.WHITE); panel.setComponentPopupMenu(menu);
        }
    }
    public static void main(String[] args) throws Exception {
        if (args.length > 0 && args[0].equals("--check")) EventQueue.invokeAndWait(() -> {
            View v = new View(); v.mark.doClick(0); v.longMode.doClick(0);
            System.out.println(v.mark.isSelected()); System.out.println(v.shortMode.isSelected() + ":" + v.longMode.isSelected());
        }); else EventQueue.invokeLater(() -> {

            f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); f.setVisible(true);

}

自己写布局：五个方法分别承担什么

有时规则很简单却不在标准布局中：所有可见项竖着排、等宽、保留各自首选高度。LayoutManager是布局协议；add/remove接收组件变化，preferred/minimum查询建议尺寸，layoutContainer安排真实边界。像一张可重复执行的摆放流程表，容器多大就重新算；类比边界是布局只安排几何，不执行按钮业务，也不能凭空创造足够空间。

import java.awt.*;
import javax.swing.*;
public class VerticalStack {
    static class Stack implements LayoutManager {
        final int gap; Stack(int gap) { if (gap < 0) throw new IllegalArgumentException("gap"); this.gap = gap; }
        public void addLayoutComponent(String name, Component c) { }
        public void removeLayoutComponent(Component c) { }
        private Dimension measure(Container p) {
            Insets in = p.getInsets(); int width = 0, height = 0, count = 0;
            for (Component c : p.getComponents()) if (c.isVisible()) {
                Dimension d = c.getPreferredSize(); width = Math.max(width, d.width); height += d.height; count++;
            }
            return new Dimension(width + in.left + in.right, height + Math.max(0, count - 1) * gap + in.top + in.bottom);
        }
        public Dimension preferredLayoutSize(Container p) { synchronized (p.getTreeLock()) { return measure(p); } }
        public Dimension minimumLayoutSize(Container p) { synchronized (p.getTreeLock()) { return measure(p); } }
        public void layoutContainer(Container p) {
            synchronized (p.getTreeLock()) {
                Insets in = p.getInsets(); int y = in.top, width = Math.max(0, p.getWidth() - in.left - in.right);
                for (Component c : p.getComponents()) if (c.isVisible()) {
                    int h = c.getPreferredSize().height; c.setBounds(in.left, y, width, h); y += h + gap;
                }
            }
        }
    }
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JPanel p = new JPanel(new Stack(5)); p.setBorder(BorderFactory.createEmptyBorder(2, 2, 2, 2));
            p.add(new JButton("一")); p.add(new JButton("二")); JButton hidden = new JButton("隐藏"); hidden.setVisible(false); p.add(hidden);
            p.setSize(200, 120); p.doLayout(); int n = 0; for (Component c : p.getComponents()) if (c.isVisible()) n++;
            System.out.println("visible=" + n); p.removeAll(); System.out.println("emptyHeight=" + p.getPreferredSize().height);
        });
    }
}

这个程序不打开窗口。两项可见、第三项隐藏，输出visible=2；清空后首选高度为4（上下各2留白）。for循环只统计visible，gap只在相邻两项之间出现；getInsets读的是容器边框留白。每次从当前列表计算，删除/隐藏不会留下旧缓存。synchronized(parent.getTreeLock())保护布局树相关操作，具体锁机制在并发章深化；当前读法是“括号内对象作为这段操作共同遵守的锁”，不能理解成开启新线程。

只改隐藏项setVisible(true)，预测高度增加该项首选高再加一个gap。独立任务：将gap设0，与空容器比较；不要直接运行教材圆形布局就以为处理了空项、全隐藏及缓存失效。绝对定位setLayout(null)/setBounds只适合确知边界的场景，一般表单采用布局以适应字体、语言、缩放。BoxLayout用于单轴排列，SpringLayout表达组件间约束，本课不强制用它们重写已工作的表单。

焦点还要真实窗口检查：按Tab/Shift+Tab观察可编辑字段和按钮，禁用/隐藏项通常不会成为可用焦点目标。默认焦点遍历受容器策略和环境影响，不能只凭添加顺序承诺每个平台完全一致。requestFocusInWindow是请求并返回是否成功，不是强制抢焦点；字段labelFor、合理顺序和可见提示比不断抢焦点更有用。
