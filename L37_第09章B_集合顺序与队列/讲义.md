## 学完要能做什么

能按需要选HashSet/LinkedHashSet/TreeSet；解释比较0判重；用Deque表达先进先出/后进先出，正确取优先队列而不猜迭代顺序。

## 不重复，不代表排好序；有顺序，也可能不是插入顺序

**Set**保存不重复的元素，HashSet按equals/hashCode识别值；LinkedHashSet还保留首次插入次序；TreeSet按自然顺序或比较器组织，**比较结果0就视为同一个集合位置**。像登记名字时可以按首次到场排，也可以按字典排；类比边界是计算机按明确比较契约，不懂“这两个姓名看起来只是同长”。

```java
import java.util.Comparator;
import java.util.LinkedHashSet;
import java.util.Set;
import java.util.TreeSet;
public class SetOrderChoices {
    public static void main(String[] args) {
        Set<String> arrival = new LinkedHashSet<>();
        System.out.println(arrival.add("bb"));
        System.out.println(arrival.add("a"));
        System.out.println(arrival.add("bb"));
        System.out.println(arrival);
        System.out.println(new TreeSet<>(arrival));
        Set<String> lengths = new TreeSet<>(Comparator.comparingInt(String::length));
        lengths.add("a"); lengths.add("b");
        System.out.println(lengths);
    }
}
```

六行依次true、true、false、[bb, a]、[a, bb]、[a]。前三条add说明重复bb不再改变集合。LinkedHashSet保留bb后a的到场顺序；TreeSet自然排序a后bb。长度比较器让a与b同序，因此仅保留第一项a。它没有自动改成equals判重，若希望保留二者，需要长度相同后再按字典比较。

| 容器 | 判重依据 | 遍历约定 |
|---|---|---|
| HashSet | equals/hashCode | 无顺序保证 |
| LinkedHashSet | equals/hashCode | 通常按首次插入次序 |
| TreeSet | compare返回0 | 比较器顺序 |

HashSet无顺序保证不等于每次运行都随机洗牌；教材p348/364的“随机”应这样理解。不同值也可同hash，p363的相反表述不能当契约，L21碰撞已验证。放入Set后不要改变影响相等/散列/排序的字段；容器不会跟着字段变化自动修复位置。

只把按长度的比较器加thenComparing自然顺序，a/b都会保留。独立任务：为任务按优先级再标题建立稳定可解释的全序，同时说明是否与业务equals一致。树的比较0与equals不一致时，虽可运行，也会违反调用者通常对Set的值相等预期，应明确或改设计。

## 队列先规定取出规则，双端队列再提供两头

Queue常用offer入、poll取、peek看而不取。空时poll/peek返回null，remove/element则抛NoSuchElementException。Deque支持两头操作，addLast/pollFirst可表达先进先出；push/pop作用同一头，表达后进先出的栈。ArrayDeque不接null，所以null可清楚表示没取到元素。

ArrayDeque按需扩容，构造容量不是固定上限，仍受可用资源限制。不能把书本p346循环数组示意的有界描述套成ArrayDeque的契约，官方[ArrayDeque说明](https://docs.oracle.com/javase/8/docs/api/java/util/ArrayDeque.html)明确可增长。阻塞有界队列在L52再学。

PriorityQueue按比较器每次取当前最小项；它的迭代或toString不承诺完整有序。要按优先顺序处理就重复poll，取走会改变队列；若要保留原队列，先复制。相同优先级不保证先入先出，需要次级序号就自己加入比较规则。下面分开运行双端与优先实验，别用一张“都有序”的标签概括它们。

## 同一双端队列，采用不同端点就表达不同流程

```java
import java.util.ArrayDeque;
import java.util.Deque;
public class DequeTwoProtocols {
    public static void main(String[] args) {
        Deque<String> queue = new ArrayDeque<>();
        queue.offerLast("A"); queue.offerLast("B");
        System.out.println(queue.pollFirst()); System.out.println(queue.pollFirst());
        queue.push("A"); queue.push("B");
        System.out.println(queue.pop()); System.out.println(queue.pop());
        System.out.println(queue.poll());
    }
}
```

前两行A/B是排队FIFO；接着B/A是栈LIFO；末行null表示空poll。offerLast尾部入，pollFirst头部出；push在头部入，pop也从头部出。`while(!isEmpty())`可遍历，但不要让null元素与空信号混淆，ArrayDeque本来禁止null。

状态：排队[A,B]→取A剩[B]→取B空；栈push A→[A]，push B→[B,A]，pop B→[A]，pop A空。只将第二次入队B改C，排队与栈各自结果按规则计算。独立任务：用addFirst/addLast明确重写push/pop路线，解释“Deque是实现栈的一种选择”，而不是所有双端队列只能作栈。

## 优先队列取最小，但不会为遍历承诺完整排序

```java
import java.util.Arrays;
import java.util.PriorityQueue;
public class PriorityDrill {
    public static void main(String[] args) {
        PriorityQueue<Integer> queue = new PriorityQueue<>();
        queue.addAll(Arrays.asList(3, 1, 2, 1));
        while (!queue.isEmpty()) System.out.println(queue.poll());
        System.out.println(queue.poll());
    }
}
```

输出1、1、2、3、null。循环每轮poll移除当前最小值，size由4到0；重复的1都保留，和TreeSet不同。不要给toString的堆内部排列写固定期望，也别在元素入队后随意改排序字段，队列不保证自动重排。

只把比较器改Comparator.reverseOrder，取出会3、2、1、1。独立任务：任务有优先级与到场序号，比较先优先级再序号，说明这是你显式增加的同优先级规则，不能从数值重复样本推断API自带稳定排队。

在课程根目录PowerShell运行`./java.ps1 -Source './L37_第09章B_集合顺序与队列/code/PriorityDrill.java'`。
