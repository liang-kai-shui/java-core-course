> 前置：L12封装；L17包；L38映射；L46交付；L47配置；L53 Future
> 教材主线：第4–14章综合（原创项目）；**书本 p91–709 / PDF p109–727**。讲解、类比、案例与练习均为课程原创。

## 学完要能做什么

能从需求划清类职责，解释真实目录到包全名的对应；实现不可变记录、完整校验再提交、UTF-8文本往返和快照后台统计；给出正常/空数据/坏输入/失败不污染旧状态的证据，制作可移动JAR。

## 学了很多类，自己的程序为什么还是全挤在main里

类按职责分，是为了让一条规则有明确归属。像学习资料分成原始登记、整理规则、文件柜、报告员和接待台；类比边界是一个职责不机械等于一个类，分太碎也会增加阅读成本。这个项目按五件真实工作拆文件，拒绝只把main复制五份改名字。

我们做一个**学习记录簿**：每条有正整数id、非空标题、0–1000000分钟与完成状态；id唯一；按加入顺序列出。可标记完成，统计已完成分钟和未完成条数，使用明确的UTF-8制表分隔格式导入/导出。它不修改课程的练习、个人进度或教材，不从“运行程序”推断学生掌握；这里的记录是你主动提供的数据。

### 把需求变成可验证的约定

| 需求 | 谁负责 | 不变量/失败 |
|---|---|---|
| 单条数据合法 | StudyEntry构造器 | id>0，标题无换行/制表符，分钟在范围 |
| id唯一、加入顺序 | StudyBook | 重复拒绝，不覆盖原项 |
| 标记状态 | StudyBook + Entry.withCompleted | 替换新值，不让快照中的旧值变化 |
| 文本协议 | StudyStore | 一行四列，解析整份再返回，坏行报告行号 |
| 统计 | StudyReport | 只读取快照，无控件和磁盘职责 |
| 参数、提示、池关闭 | Main | 失败明确报告，不输出虚假的保存成功 |

当前是单个CLI协调者修改StudyBook，后台仅看不可变记录的列表快照；**不是**多个线程可以同时随意改StudyBook。以后若加GUI，模型修改集中EDT，后台仍拿启动时快照，结果回EDT展示；不要给每个方法随便加锁就宣称整个应用事务安全。

## 先用一个完整小程序理解快照边界

```java
import java.util.*;
import java.util.concurrent.*;
public class SnapshotReportWarmup {
    public static void main(String[] args) throws InterruptedException, ExecutionException {
        List<Integer> live = new ArrayList<>(Arrays.asList(30, 20)); List<Integer> snapshot = new ArrayList<>(live); live.add(1000);
        ExecutorService pool = Executors.newSingleThreadExecutor();
        try { Future<Integer> result = pool.submit(() -> { int sum = 0; for (int n : snapshot) sum += n; return sum; }); System.out.println(result.get()); System.out.println("live-size=" + live.size()); }
        finally { pool.shutdownNow(); if (!pool.awaitTermination(3, TimeUnit.SECONDS)) throw new IllegalStateException("pool active"); }
    }
}
```

先取快照{30,20}，原列表再加1000，后台仍算50，输出50和live-size=3。复制容器不等于深复制元素；这里Integer不可变，后面的StudyEntry也设计为不可变，所以浅拷贝容器足够隔离后续状态替换。若元素可变，new ArrayList仅复制引用，不会冻结其字段。

只把snapshot赋值改为live引用，工作在live.add之后才提交，结果将1050；这是顺序安排的对照，不靠随机竞争。独立任务画出两个列表的格子和共享/不共享的对象，再进入多文件项目。

## 先建立模型，再接文件与线程

先做StudyEntry，正常值能构造，负分钟、空标题立即拒绝；再做StudyBook，加入两项、重复id拒绝、切换状态替换对象。之后才接StudyStore，最后把快照交StudyReport和执行器。每层都跑通再加下一层，报错时可以知道新问题在哪，而不是面对一个大程序随机删代码。

文本协议是本课程原创简化格式，**不是CSV通用解析器**。一行按`id<TAB>minutes<TAB>true或false<TAB>title`，标题禁止换行/制表符以免歧义；标题可含普通空格和中文。布尔值明确只接受true/false，不用Boolean.parseBoolean把任意bad无声变false。split第二参数-1保留尾部空列，才能发现空标题；四列检查、数字解析、构造器验证逐步进行。

导入先构建新StudyBook，整份成功后才交调用者替换；坏行不把前半份偷偷塞进已有记录。导出本课仅CREATE_NEW：目标已存在就报告already-exists，避免无意覆盖；这不等于已经实现完整的原子替换保存。真实更新保存可在第二阶段设计同目录临时文件、成功后替换及备份，并核对平台支持，不把直接覆盖中途失败说成安全。

package campus.model;
public final class StudyEntry {
    private final int id, minutes; private final String title; private final boolean completed;
    public StudyEntry(int id, String title, int minutes, boolean completed) {
        if (id <= 0 || title == null || title.trim().isEmpty() || title.indexOf('\t') >= 0 || title.indexOf('\n') >= 0 || title.indexOf('\r') >= 0 || minutes < 0 || minutes > 1000000) throw new IllegalArgumentException("invalid entry");
        this.id = id; this.title = title.trim(); this.minutes = minutes; this.completed = completed;
    }
    public int getId() { return id; }
    public String getTitle() { return title; }
    public int getMinutes() { return minutes; }
    public boolean isCompleted() { return completed; }
    public StudyEntry withCompleted(boolean value) { return new StudyEntry(id, title, minutes, value); }
}

package campus.model;
import java.util.*;
public final class StudyBook {
    private final Map<Integer, StudyEntry> entries = new LinkedHashMap<>();
    public void add(StudyEntry entry) {
        if (entry == null || entries.containsKey(entry.getId())) throw new IllegalArgumentException("duplicate or null entry");
        entries.put(entry.getId(), entry);
    }
    public void setCompleted(int id, boolean value) {
        StudyEntry old = entries.get(id); if (old == null) throw new NoSuchElementException("unknown id: " + id);
        entries.put(id, old.withCompleted(value));
    }
    public List<StudyEntry> snapshot() { return new ArrayList<>(entries.values()); }
}

package campus.io;
import java.io.*;
import campus.model.StudyBook;
import campus.model.StudyEntry;
public final class StudyStore {
    private StudyStore() { }
    public static StudyBook read(Reader source) throws IOException {
        BufferedReader reader = source instanceof BufferedReader ? (BufferedReader) source : new BufferedReader(source);
        StudyBook draft = new StudyBook(); String line; int number = 0;
        while ((line = reader.readLine()) != null) {
            number++;
            try {
                String[] fields = line.split("\t", -1); if (fields.length != 4) throw new IllegalArgumentException("need four fields");
                int id = Integer.parseInt(fields[0]), minutes = Integer.parseInt(fields[1]);
                if (!fields[2].equals("true") && !fields[2].equals("false")) throw new IllegalArgumentException("invalid boolean");
                draft.add(new StudyEntry(id, fields[3], minutes, fields[2].equals("true")));
            } catch (IllegalArgumentException e) { throw new IOException("invalid line " + number, e); }
        }
        return draft;
    }
    public static void write(StudyBook book, Writer target) throws IOException {
        for (StudyEntry e : book.snapshot()) {
            target.write(e.getId() + "\t" + e.getMinutes() + "\t" + e.isCompleted() + "\t" + e.getTitle() + "\n");
        }
        target.flush();
    }
}
```

package campus.report;
import java.util.List;
import campus.model.StudyEntry;
public final class StudyReport {
    private final int entries, pending; private final long completedMinutes;
    private StudyReport(int entries, int pending, long completedMinutes) { this.entries = entries; this.pending = pending; this.completedMinutes = completedMinutes; }
    public static StudyReport summarize(List<StudyEntry> snapshot) {
        long minutes = 0; int pending = 0;
        for (StudyEntry entry : snapshot) { if (entry.isCompleted()) minutes += entry.getMinutes(); else pending++; }
        return new StudyReport(snapshot.size(), pending, minutes);
    }
    public int getEntries() { return entries; }
    public int getPending() { return pending; }
    public long getCompletedMinutes() { return completedMinutes; }
}
```

### src/campus/app/Main.java

<!-- source: code/project/src/campus/app/Main.java -->
```java-source
package campus.app;
import java.io.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.util.*;
import java.util.concurrent.*;
import campus.model.*;
import campus.io.StudyStore;
import campus.report.StudyReport;
public class Main {
    static StudyBook seed() {
        StudyBook book = new StudyBook(); book.add(new StudyEntry(1, "数组", 30, false)); book.add(new StudyEntry(2, "循环", 20, true)); book.add(new StudyEntry(3, "类", 15, false)); book.setCompleted(1, true); return book;
    }
    static void report(StudyBook book) throws InterruptedException, ExecutionException {
        List<StudyEntry> snapshot = book.snapshot(); ExecutorService pool = Executors.newSingleThreadExecutor();
        try {
            StudyReport result = pool.submit(() -> StudyReport.summarize(snapshot)).get();
            System.out.println("entries=" + result.getEntries()); System.out.println("completed-minutes=" + result.getCompletedMinutes()); System.out.println("pending=" + result.getPending());
        } finally { pool.shutdownNow(); if (!pool.awaitTermination(3, TimeUnit.SECONDS)) throw new IllegalStateException("report pool active"); }
    }
    static void checkErrors() throws IOException {
        StudyBook old = seed();
        try { old.add(new StudyEntry(1, "重复", 0, false)); } catch (IllegalArgumentException e) { System.out.println("duplicate-rejected"); }
        try { new StudyEntry(4, "负数", -1, false); } catch (IllegalArgumentException e) { System.out.println("negative-rejected"); }
        try { old.setCompleted(99, true); } catch (NoSuchElementException e) { System.out.println("unknown-rejected"); }
        String[] invalid = {"1\t20\ttrue\t好\n2\tbad\tfalse\t坏\n", "1\t0\tyes\t坏\n", "1\t0\ttrue\t\n", "1\t0\ttrue\tA\n1\t0\tfalse\tB\n", "1\t0\ttrue\n"};
        for (String text : invalid) { try { old = StudyStore.read(new StringReader(text)); throw new AssertionError("invalid accepted"); } catch (IOException expected) { System.out.println(expected.getMessage()); } }
        System.out.println("preserved=" + old.snapshot().size()); System.out.println("empty=" + StudyStore.read(new StringReader("")).snapshot().size());
        List<StudyEntry> snapshot = old.snapshot(); old.setCompleted(3, true); System.out.println("snapshot-old=" + !snapshot.get(2).isCompleted());
    }
    public static void main(String[] args) throws InterruptedException, ExecutionException {
        try {
            if (args.length == 1 && args[0].equals("--check-errors")) { checkErrors(); return; }
            StudyBook book = seed();
            if (args.length == 2 && args[0].equals("--load")) {
                try (Reader in = Files.newBufferedReader(Paths.get(args[1]), StandardCharsets.UTF_8)) { book = StudyStore.read(in); }
            } else if (args.length == 2 && args[0].equals("--new")) {
                try (Writer out = Files.newBufferedWriter(Paths.get(args[1]), StandardCharsets.UTF_8, StandardOpenOption.CREATE_NEW)) { StudyStore.write(book, out); }
                System.out.println("saved"); return;
            } else if (args.length != 0) { System.out.println("usage: --load path | --new path | --check-errors"); return; }
            report(book); StringWriter text = new StringWriter(); StudyStore.write(book, text); StudyBook restored = StudyStore.read(new StringReader(text.toString()));
            System.out.println("restored=" + restored.snapshot().size());
        } catch (FileAlreadyExistsException e) { System.out.println("already-exists"); }
        catch (IOException e) { System.out.println("io-error:" + e.getMessage()); }
    }
}
```

### 把一次默认运行逐步追踪

Main.seed先建三条，再将id1换成completed=true的新Entry；snapshot保留当前三个不可变Entry引用。report创建一个单线程池，提交只读快照的任务；get成功才显示统计，finally关闭并等结束。此处数据很少，用线程只是整合教学，不声称三个数据也有性能收益。

| 步骤 | 正式簿 | 传给后台 | 可见输出 |
|---|---|---|---|
| seed | 1完成30、2完成20、3待办15 | 尚无 | 无 |
| snapshot | 仍3项 | 新List，三个不可变值 | 无 |
| summarize | 不修改 | 合计完成50、待办1 | 返回Report |
| Main展示 | 不修改 | 已完成 | entries=3等三行 |
| write/read内存往返 | 不修改旧簿 | 新Reader得到新簿 | restored=3 |

只改第3项的完成状态为true，预测completed-minutes=65、pending=0，entries/restored仍3。再改负分钟，应在构造阶段失败，不会先输出一个似是而非的报告。

### 第一轮排错按边界进行

编译找不到类型：先查package、import、项目源清单；启动找不到主类：查classpath根和Main-Class；字段校验失败：查Entry构造参数；重复id：查Book的键规则；invalid line：查文本四列与范围；get抛ExecutionException：看原始cause；进程不退出：查执行器是否经过finally关闭。不要对所有问题都删掉package，或者catch(Exception)后一律输出success。

基础成品到此已经能独立运行。若做可选GUI，可在EDT维护Book，选文件后后台读出新Book，done成功才替换；启动报告时取快照，取消和失败保持原正式状态。不要直接从后台给旧Book边读边add，也不要为了复用逻辑把JLabel塞入StudyReport。

本项目覆盖模型、容器、异常、文本I/O、后台结果和JAR装配；不会强迫每个关键词都出现。反射、动态代理、复杂图形、读写锁等有各自适用问题，本项目无需制造无意义的用法来凑全书清单。
