## 1. 文本不只是给数字换一种输出

程序要保存姓名、消息、课程名称。**字符串**是一段文本，Java 用 String 表示它。例如 `String name="Li Ming";`建立一个保存文本引用的变量。

**对象**可以先理解为运行中具有类型和相关操作的一项数据实体。String 对象代表一段文本。类 String 规定这种数据怎样使用；具体的 "Li Ming" 是一段实际文本。类与对象的完整设计以后再学，本课先要分清“变量”与“变量找到的文本”。

**引用**是程序用来找到对象的值。类比一张取件凭证：变量保存凭证，凭证能找到包裹；把凭证复制两份，包裹不一定变成两份。类比不表示你可以看到真实地址或任意加减地址；Java 引用没有这样的指针算术。

```text
变量 name ──引用──> String 对象：Li Ming
```

## 2. 调用一个方法，到底交出和拿回什么

**方法调用**是请求一个现成操作做一次工作。先读成 `对象.操作(输入)`。有些操作返回一个结果，有些只做动作；不能看到调用结束就认为原变量已经被改。

```java
public class TextOperations {
    public static void main(String[] args) {
        String word = "Java";
        int length = word.length();
        String part = word.substring(1, 3);
        System.out.println(length);
        System.out.println(part);
        System.out.println(word);
    }
}
```

输出 4、av、Java。拆开第二个调用：

| 部分 | 在本例的含义 |
|---|---|
| word | 通过它找到要操作的文本 |
| substring | 操作的名字：取一段子串 |
| (1, 3) | 交给操作的两个编号参数 |
| 返回结果 | 得到文本 av |
| String part = | 将结果的引用保存到 part |

`length()`没有参数，括号仍要保留，表示调用；结果是 int 长度。括号中的逗号分隔参数，不是字符串正文。

这一课遇到方法时先问四句：对谁操作、交给它什么、它返回什么、是否改变原对象。API 是工具提供的使用约定，包含这些信息；不是神秘的新编程语言。

## 3. trim 没效果？先分清忽略结果与重新赋值

**不可变**在 String 上指对象建立后的文本内容不会被这些方法改写。想得到另一段文本，使用返回结果；变量本身仍可以指向另一个对象。

```java
public class TrimWalk {
    public static void main(String[] args) {
        String original = "  Java  ";
        original.trim();
        System.out.println("original=[" + original + "]");
        String cleaned = original.trim();
        System.out.println("cleaned=[" + cleaned + "]");
        System.out.println("still original=[" + original + "]");
        original = cleaned;
        System.out.println("reassigned=[" + original + "]");
    }
}
```

输出的方括号是我们主动加的，用来让两侧空格可见：

```text
original=[  Java  ]
cleaned=[Java]
still original=[  Java  ]
reassigned=[Java]
```

按三个时刻画图：

```text
① original ──> [  Java  ]
   调用 trim 并丢弃结果：original 仍指向这段原文本

② original ──> [  Java  ]
   cleaned  ──> [Java]      把处理结果另存下来

③ original ──┐
             ├─> [Java]    重新给变量赋值，不是改写原文本
   cleaned ──┘
```

类比给照片另做裁剪版：得到裁剪结果与让某个标签指向裁剪版，是两个动作。不要从类比推断所有方法必然分配新对象；例如无需裁剪时 trim 可以返回原对象，本课关心的是内容不被改写及返回值的使用。

Java 8 的 trim 按自己的字符规则去两端相应空白，不等于去除任意 Unicode 空白，也不会删除姓名中间的空格。先用普通空格做练习。

随堂实验：去掉最后的 original=cleaned，预测最后一行；再把原始文本改为 "  Li Ming  "，中间空格应该保留。

## 4. 两份内容相同，是否就是同一对象

**内容相等**问文本是否一样；**同一对象**问两个引用是否找到同一个对象。两个文件都写着 Java，不能据此说它们就是同一个文件。类比说明问题不同，不是说 String 对象真是磁盘文件。

```java
public class TextEqualityWalk {
    public static void main(String[] args) {
        String first = "Java";
        String alias = first;
        String other = new String("Java");
        System.out.println(first == alias);
        System.out.println(first == other);
        System.out.println(first.equals(other));
        System.out.println(first.equals("java"));
    }
}
```

输出 true、false、true、false。`new String("Java")`在这里明确建立另一个 String 对象；平常不必为了比较文字特意这样创建，本例用它把两种问题分开。

```text
first ─┐
       ├─> 对象 A：Java
alias ─┘
other ───> 对象 B：Java
```

引用的 == 比较是否同一对象；String.equals 比较文本内容，默认区分大小写。给用户输入的命令作内容判断，不能用“我试过两个字面量 == 为真”证明可以使用 ==。字面量可能共享对象，那恰好掩盖了错误。

### 空字符串和 null

`""`是确实存在、但长度为 0 的文本；`null`表示引用没有指向对象。空箱子与没有箱子可帮助记差别，但 null 不是一个内容叫“空”的特殊 String。

`"".length()`得到 0；若变量 absent 为 null，调用 `absent.length()`会产生空指针异常。这里有一个容易误读的错误：源码直接写 `null.length()`本身不是合法的这类调用实验；应先有 String 变量，再让它的值为 null，在副本观察运行失败。

`"yes".equals(answer)`以确定存在的字面量作调用者，即使 answer 是 null 也能返回 false。这只是这个调用的安全性质，不代表别的 null 操作都安全。

## 5. 字符编号：长度与最后一个位置不同

给 Java 的四个代码单元编号：

```text
位置：     0   1   2   3
文本：    [J] [a] [v] [a]
边界：   0   1   2   3   4
```

**下标**是访问位置用的编号，Java 从 0 开始。length() 是 4，合法 charAt 下标是 0–3。

**子串**是原文本里连续的一段。`substring(begin,end)`包含 begin，不包含 end，选中位置 begin 到 end−1。像在格子边界上插两张卡，拿走两卡之间的格子。

| 调用 | 选中哪些位置 | 结果 |
|---|---|---|
| charAt(0) | 单个位置 0 | 'J' |
| substring(1,3) | 1、2 | "av" |
| substring(0,4) | 0、1、2、3 | "Java" |
| substring(2,2) | 没有格子 | "" |

begin 和 end 相同可以得到空串；但倒过来、超过长度或使用负位置会违反范围。`charAt(length())`是在第四格之后取字符，应运行时失败；`substring(length(),length())`却可以得到空串，两个方法的边界条件不同。

先做纸上题："Li Ming"长度为 7，前两个单元在哪些位置？应取 substring(0,2)，不是 substring(1,2)。若不画下标，很容易把人的“第一个”直接写成 1。

## 6. + 从哪一步变成文本拼接

**拼接**是把几段文本接成一段。当 + 的运算涉及 String 时会进行字符串拼接：

```text
"score=" + 80 + 5      → "score=80" + 5 → "score=805"
"score=" + (80 + 5)    → "score=" + 85 → "score=85"
80 + 5 + " points"     → 85 + " points" → "85 points"
```

先算哪个部分，由语法规则与括号决定，不是由“看起来像分数相加”决定。先算数值，再加标签，可以减少混淆。

练习 NameCard 的路径：先保存 raw；另建 cleaned=raw.trim()；先输出带方括号的两份文本检查空格；再加长度和前两个位置的子串。这样一旦截取不对，就能分清是 trim、下标还是输出的问题。

## 7. 构建器：明确要反复追加的工具

**StringBuilder**是可以改变内容的文本构建工具。像草稿板逐段追加，最后交出一份 String 结果。它与不可变 String 的操作性质不同，不能见到“文本方法”就一律以为不改变原对象。

```java
public class BuilderWalk {
    public static void main(String[] args) {
        StringBuilder draft = new StringBuilder();
        draft.append("Java");
        System.out.println("step1=[" + draft.toString() + "]");
        draft.append(" ");
        draft.append("course");
        String result = draft.toString();
        System.out.println("result=[" + result + "]");
        draft.append("!");
        System.out.println("saved=[" + result + "]");
        System.out.println("draft=[" + draft.toString() + "]");
    }
}
```

输出 step1=[Java]、result=[Java course]、saved=[Java course]、draft=[Java course!]。append 改变构建器；toString 得到当前的 String 文本，之后改构建器不让已保存的 result 自动跟随。

先把每次操作分成独立行。以后见到 `draft.append("Java").append(" course")`，它是连续调用，不必为了少写行数提前模仿。

## 8. length 为什么不总是屏幕上的字数

**码点**是 Unicode 分配给字符的编号；**代码单元**是 UTF-16 表示采用的单位。一个码点可能需要一个或两个代码单元；人眼看到的一个图形还可能由多个码点组合。

```java
public class UnicodeWalk {
    public static void main(String[] args) {
        String text = "A😀中";
        System.out.println(text.length());
        System.out.println(text.codePointCount(0, text.length()));
    }
}
```

本例代码单元长度 4，码点数 3。charAt 一次取一个代码单元，不能保证取到整个 emoji。这里不要求写通用文字切分器，也不要把 codePointCount 一概称为视觉字数。

本课过关：能画变量到文本的关系，解释忽略返回值、重新赋值与不变性的差别；内容比较选 equals；正确截取指定文本；知道空串与 null 不同。Unicode 的复杂遍历只作深化。

## 对齐3.6.7–3.6.8：学会读一条API，不靠记住所有名字

教材不只列字符串方法，还教如何读文档。以`int indexOf(String str)`为例：最前int是返回类型，indexOf是方法名，括号说明要交一个String参数。形参名str是文档里的名字，不要求调用方变量也取这个名字。

假设`String title="Java course";`，调用title.indexOf("course")得到5；调用title.indexOf("Python")得到−1。它返回位置，不返回找到的正文；没找到时不要把−1直接交给substring作合法下标。

阅读步骤：先在[String官方API](https://docs.oracle.com/javase/8/docs/api/java/lang/String.html)定位类；找Method Summary中的方法名；再读参数、返回值和Throws里的失败条件。页面样式可以不同，读的内容相同。教材条目旁的版本数字说明何时加入，不是要求你下载这个版本。

常见任务的小字典：

| 任务 | 可以查什么 | 先核对的边界 |
|---|---|---|
| 判断前缀/后缀 | startsWith、endsWith | 区分大小写，结果是boolean |
| 忽略大小写比较简单文本 | equalsIgnoreCase | 不等于任意语言的排序规则 |
| 找位置 | indexOf、lastIndexOf | 找不到为−1 |
| 换一段正文 | replace | String原对象不改变 |
| 统一大小写 | toLowerCase、toUpperCase | 大小写规则可能受地区影响 |
| 用分隔符连接 | String.join | 分隔符是你明确提供的文字 |

看到CharSequence参数时，本阶段可先交String，它是可接受的类型；接口体系第6章再展开。不需要为会调用一个方法先背完继承结构。

构建器除append外还可insert、delete、setCharAt。它们与String的不可变操作不同；delete也采用起点含、终点不含的范围。第一遍先熟练append与toString，其余会查，不增加本课必交工作。
