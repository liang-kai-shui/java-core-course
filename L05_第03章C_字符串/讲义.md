## 这一课要解决什么问题

电脑怎样保存姓名、拼接消息、比较文本、截取一部分？不要把字符串当成C++字符数组照搬。

## 1. String与不变性

**字符串**是一段文本，例如`"Java"`；Java用`String`类表示它。**方法调用**是请求某个对象或类完成一个操作，写法先读成“对象.操作(参数)”。参数是交给操作的数据，返回值是操作得到的结果。

```java
String name = "  Java  ";
name.trim();
System.out.println(name);
name = name.trim();
```

**不可变**表示已经建立的String对象内容不会被这些操作改写。`trim()`返回去掉首尾相应空白的新结果；不接住结果，name还是原来的引用。这里的**引用**可类比找到对象的凭证，但不是能自己做地址算术的指针。重新给变量赋值与修改原对象不是一回事。

## 2. 内容比较用equals

`a.equals(b)`比较字符串内容；引用上的`==`比较是否指向同一对象。一些字面量可能共享对象，导致`==`偶尔看似能比内容，不能因此拿它判断用户输入的文本。

空字符串`""`是存在但没有内容的String；`null`是没有指向对象。`null.length()`会报异常，不是0。已知常量时可写`"yes".equals(answer)`，answer为null也不会因为调用者为null而报错；不要因此认为所有null操作都安全。

## 3. 下标从0，终点不包含

`"Java".charAt(0)`得到'J'。`substring(1,3)`取下标1、2，得到`"av"`；结束下标不包含，像从起点格子走到终点前停下。`length()`是代码单元个数，合法charAt下标从0到length()-1。空串没有可取的第0个元素。

`"score="+80+5`会先拼接成文本再继续拼接，得到`score=805`；要先求和写`"score="+(80+5)`。

## 4. Unicode与StringBuilder

String内部使用UTF-16代码单元语义；emoji等补充字符可能占两个代码单元。运行UnicodeDemo，比较length和codePointCount。**码点**是Unicode给字符分配的编号；它与“视觉上一个字形”也不总是一对一。先知道边界，本课不要求实现通用字素切分。

反复拼很多片段时，可以用**StringBuilder**这个可变文本构建工具，像先在草稿板上逐段追加，最后`toString()`交出String。`append`会改变构建器，区别于String上的不可变操作。先运行示例，不要求在还没学循环时优化所有字符串。
