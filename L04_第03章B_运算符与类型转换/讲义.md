## 这一课要解决什么问题

相同数字，为什么换个类型或括号就得到不同答案？先确定表达式怎样算，再给结果起名。

## 1. 整数除法发生在赋值之前

**表达式**是会计算出结果的组合，像一张小算式。`7 / 2`两侧是整数，结果是3；`double x = 7 / 2`只是把已经得到的3再转成3.0。要得到3.5，让运算本身含double：`7 / 2.0`。`%`是余数，不是百分比。

负整数除法向0截断，例如`-7/2`是-3，`-7%2`是-1。乘法和除法优先于加减，但涉及业务含义时主动加括号比硬背复杂优先级更清楚。

教材3.5.1还会用到`Math`这个数学工具类：`Math.sqrt(9.0)`得到平方根3.0，`Math.pow(2.0, 3.0)`得到8.0。这里的点表示调用该类提供的方法，不是小数点。Java中的`^`是按位异或，不是乘方；想算平方也可直接写`x * x`。本阶段只需按API说明调用，第4章再展开静态方法。

## 2. 类型转换不能修复已经算坏的结果

**转换**是把值用另一种类型表示。**强制转换**写成`(int)3.9`，结果是3，丢掉小数部分，不是四舍五入。

```java
int count = 1_000_000;
long wrong = count * count;
long right = (long) count * count;
```

第一种先按int相乘并溢出，装进long也救不回来；第二种在乘之前就让计算使用long。即使int转double通常能表示，long转double仍可能丢精度，不能认为“目标容量大就什么都不丢”。

`+=`等组合赋值有隐式转换规则，例如`short s=1; s+=1`可行，直接`s=s+1`不一定可行。本课优先写清楚表达式，不靠隐式转换省字。`i++`先给出旧值再加1，`++i`先加1再给出值；在独立一行作为更新时相同，避免堆在一个复杂算式里。

## 3. 比较与短路

`==`比较是否相等，`=`赋值；`!=`不等。`&&`表示同时成立，`||`表示至少一个成立，`!`取反。它们处理boolean，不把整数自动当真假。

**短路**是已经知道结果时不再执行右边，像两道门中第一道明确不通就不必检查第二道。`divisor != 0 && 10 / divisor > 1`在除数为0时不会计算除法。`&`和`|`用于boolean时会计算两边，也可用于整数位运算；与`&&`、`||`不要混用。

三目表达式`score >= 60 ? "pass" : "retry"`根据条件选一个值。位运算的`& | ^ ~ << >> >>>`先知道作用在二进制位；本课扩展阅读，不要求用它写业务题。3.5.9枚举先理解“给有限选项起名字”，详细设计在第5章。
