## 这一课要解决什么问题

有限的几个选项怎样分派？循环中想提前结束怎么办？整数或小数超出基本类型能力时用什么？

## 1. switch按一个值选择分支

**多重选择**是按同一个值匹配若干选项。传统Java8写法中，`case`标出选项，`default`处理未匹配情况，`break`结束当前switch。没有break时可能继续执行后面的语句，叫**贯穿**；它有时是有意合并分支，但初学要明确标注。

```java
switch (day) {
    case 6:
    case 7:
        System.out.println("weekend");
        break;
    default:
        System.out.println("weekday");
}
```

示例假定day在1–7内；若任务要求验证范围，必须先处理0、8等非法值。switch适合离散选项，不直接写`case score >= 60`。新版箭头语法另行补充，首批练习采用教材风格。

## 2. break和continue

循环里的`break`结束最内层对应循环；`continue`跳过本轮剩余部分，转入下一轮。for中的continue会先走更新部分；while里若把更新放在continue之后，可能永远跳过更新导致死循环。

不要说continue“退出循环”；它只退出这一轮。多层嵌套和带标签跳转先会读，本课选做，不要求靠标签重写普通题。

## 3. BigInteger与BigDecimal

**大整数**`BigInteger`用于超出long范围的整数，仍受可用内存与资源限制；不是无限大。`new BigInteger("...")`从十进制文本建立值。相加写`a.add(b)`，不能写`a+b`。

**十进制数**`BigDecimal`适合明确控制十进制表示与舍入。需要精确表示0.1时用`new BigDecimal("0.1")`，避免先把0.1变成近似double再交给构造器。`BigDecimal.valueOf(0.1)`也是常见选择，但必须分清它与`new BigDecimal(0.1)`。

这些数值对象的运算返回结果，`a.add(b)`不改原a，需要保存结果。除法不一定有有限小数，`1/3`要指定保留位数和**舍入规则**，如`divide(three,2,RoundingMode.HALF_UP)`；本课用它观察“保留2位按规则取舍”，不泛称所有金额都采用同一规则。`equals`还比较scale等表示细节，数值比较用`compareTo`并检查是否为0。
