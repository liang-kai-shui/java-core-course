# L02 参考答案与解析

对应[本课练习](../练习.md)。先自己尝试，再看为什么。题目为课程原创；允许其他正确解法，参考程序也需要接受核对。以下是材料解析，不是对学生作答的批改结论。

## Q1：编译输入文件，启动查找类

| 部分 | 对应工作 |
|---|---|
| javac | 读取源码并产生class |
| -d | 指定编译结果目录 |
| java | 启动运行系统并按名称查类 |
| -cp | 指定查找类的位置 |

本课无package，类名例如HelloJava。启动写类名，不能把HelloJava.class当作这里的类名；较新JDK的源码启动是另一模式，不是本题手动两步的证据。

## Q2：搜索不到与没有安装不同

PATH没有登记工具目录，短命令可能找不到，完整工具路径仍可用。编译失败后旧class可能继续存在，运行它只能证明旧版本能启动，不能证明刚修改的源码正确。

## E1：应有哪几份证据

1. 当前目录和实际源码位置。
2. javac完整命令，包含编码、目标版本、输出目录及源码。
3. 编译成功后才执行的java命令，-cp指向本次目录。
4. 自己程序的实际输出。

方法可与讲义不同，只要隔离产物、失败停止、运行对象明确，就不必逐字照抄。

## E2：启动时传入文本

无参数计数0，red、blue两项计数2。参数来自启动调用，而不是程序后来自动读取了键盘。若把Li Ming作为带引号的一项，计数应为1。

## E3：阶段决定判断

| 标本 | 编译 | 启动/执行 | 应解释的原因 |
|---|---|---|---|
| MissingSemicolon | 失败 | 不启动本轮产物 | 缺语句标点 |
| WrongFileName | 失败 | 不启动本轮产物 | public类名与源文件名不符 |
| MissingMain | 成功 | 启动失败 | 无当前约定入口 |
| RuntimeCrash | 成功 | 运行时异常 | 执行非法数组访问 |
| WrongFormula | 成功 | 正常结束但结果错 | 合法公式不合题意 |

修复任选一个自己的副本；文件名问题要同时核对类名与文件名，入口问题要准确恢复main模板。保留原始诊断并记录修后输出。不同JDK诊断文案可以不同，不以某一句英文逐字匹配评判知识。
