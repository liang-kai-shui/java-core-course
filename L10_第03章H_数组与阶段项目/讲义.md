## 这一课要解决什么问题

保存一组成绩并统计，而不是为每个人写一个变量。本课结束做一个有明确输入输出的成绩统计器。

## 1. 数组是编号的一排同类型元素

**数组**按编号组织一组固定长度元素，像编号从0开始的储物格。`int[] scores = new int[3]`建立3个int元素，默认各为0；变量scores保存数组引用。合法下标是0、1、2，`scores.length`是3，数组length不是方法，没有括号。

**引用共享**：`int[] b = scores`复制引用，像两张凭证找到同一排格子，改b[0]会影响从scores看到的内容。`Arrays.copyOf`建立另一份数组。对引用数组做浅拷贝时元素仍可能共享对象；当前先对int数组验证。

```java
for (int i = 0; i < scores.length; i++) {
    scores[i] += 1;
}
for (int score : scores) {
    System.out.println(score);
}
```

增强for适合依次读取元素；`for(int score:scores){score++;}`只改本轮局部变量，不会把int数组元素改掉。需要下标更新时用普通for。

## 2. 不存在的位置不是“随便一个值”

访问length位置会产生越界异常。空数组`new int[0]`合法，但没有第0项；它与null不同。统计平均值先确认数量大于0；最大值对非空数组可从第一项初始化，避免把全负数误判为0。

## 3. 排序与查找有前提

`Arrays.sort`会改变原数组顺序；想保留原始录入顺序先复制。`Arrays.binarySearch`要求相应区间按同样规则有序；未找到时返回负数编码，不能把所有负结果都解释成固定-1，也不能把返回值直接当成绩。

## 4. 二维数组是数组的数组

`int[][] grid={{1,2},{3,4,5}}`两行长度不同。外层`grid.length`是行数，内层每次读`grid[row].length`；不能假设每行都等于第0行长度。**不规则数组**就是这种不等长情况。NestedArrayDemo演示遍历；不要求现在写高维算法。

**命令行参数**`String[] args`也属于数组；访问args[0]前检查长度。它与Scanner读键盘是不同的数据入口。

## 5. 阶段项目的边界

成绩统计器先读数量n，约定0–100；n=0打印`no data`并结束。n>0再读n个0–100的整数成绩，保留录入顺序，输出总分、两位小数平均分、最大值、最小值、及格人数，再另行打印排序副本。题目规定有效的成绩输入，不把字母恢复或文件保存作为本阶段卡关项。

先写输入/输出样例，再拆步骤：分配数组→读入→统计→复制排序→输出。**算法**在这里就是为解决任务安排的一系列步骤，不是背某种高深公式。
