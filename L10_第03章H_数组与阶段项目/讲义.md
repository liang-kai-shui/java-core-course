## 1. 三十个成绩，难道建立三十个变量

score1、score2……可以装数据，却很难让循环按编号自动选择它们。**数组**把一组同类型元素组织在一起，通过下标访问。像一排有编号的储物格，这排格子的长度建立后固定。

```java
public class ArrayFirstSteps {
    public static void main(String[] args) {
        int[] scores = new int[3];
        System.out.println("length=" + scores.length);
        System.out.println("initial=" + scores[0]);
        scores[0] = 70;
        scores[1] = 80;
        scores[2] = 90;
        System.out.println(scores[0]);
        System.out.println(scores[1]);
        System.out.println(scores[2]);
    }
}
```

输出 length=3、initial=0，再输出70、80、90。拆开创建语句：

| 部分 | 含义 |
|---|---|
| int[] | 变量类型是 int 数组引用 |
| scores | 自己取的变量名 |
| new int[3] | 创建长度3的 int 数组 |
| scores[0] | 访问第0号元素，位置从0开始 |

```text
scores ──> 数组对象
下标        0     1     2
值         [70]  [80]  [90]
长度        3
```

scores 保存引用，不把整个数组直接装进变量格子。数组元素各有自己的值，int 元素初始为0；这不推翻局部变量读取前必须已赋值的规则。`int[] scores;`只声明局部引用，也不能直接读取尚未赋值的 scores。

数组长度用 `.length`，没有括号；String 的 `.length()`是方法调用。两种写法由各自类型的接口决定，不是可以随意选择的排版。

## 2. 长度、末下标、空数组、null

长度3有下标0、1、2，访问 scores[3]越界。Java 会检查数组访问边界，执行非法访问时报告异常；不要把 C++ 原始数组的行为套过来。

**空数组**`new int[0]`是确实存在、长度0的数组。它没有第0项。null 则没有指向数组，连读取 length 都没有对应对象可用。

| 情况 | 能读 length 吗 | 能读第0项吗 |
|---|---|---|
| new int[3] | 能，3 | 能 |
| new int[0] | 能，0 | 不能，越界 |
| null 数组引用 | 不能，空指针异常 | 不能 |

另一个常用创建方式是 `int[] scores={70,80,90};`，长度按给出的元素数建立。创建后的数组不能原地伸长；重新 new 并赋值让变量找到另一数组，是换对象，不是把旧对象长度改了。

## 3. 复制引用，为什么改了另一边

```java
import java.util.Arrays;

public class ArrayAliasWalk {
    public static void main(String[] args) {
        int[] original = {70, 80, 90};
        int[] alias = original;
        alias[0] = 99;
        System.out.println(Arrays.toString(original));
        System.out.println(Arrays.toString(alias));
    }
}
```

两行都是 [99, 80, 90]。`Arrays.toString`把数组元素排成可读文本；直接 println(array) 不会按你希望的方式逐项列成绩。

```text
original ─┐
          ├──> [70][80][90]
alias ────┘
通过 alias 改第0项 ──> 同一对象变为 [99][80][90]
```

**别名**在这里指两条引用访问同一数组的现象。像两张取件凭证找到同一排格子，凭证多了，格子没多。

不是 original 变量自动跟随 alias 变量：若后来 alias=new int[1]，只改 alias 的引用值，original 仍指向原数组。改引用与改引用所指对象的元素是两个动作。

## 4. 真正复制元素，建立另一排格子

```java
import java.util.Arrays;

public class ArrayCopyWalk {
    public static void main(String[] args) {
        int[] original = {70, 80, 90};
        int[] copy = Arrays.copyOf(original, original.length);
        copy[0] = 99;
        System.out.println("original=" + Arrays.toString(original));
        System.out.println("copy=" + Arrays.toString(copy));
    }
}
```

输出 original=[70, 80, 90]、copy=[99, 80, 90]。

```text
original ──> [70][80][90]
copy     ──> [70][80][90]  新的 int 数组
修改 copy 的第0项不会碰到上面那排
```

Arrays 是标准库提供数组相关工具的类，import java.util.Arrays 允许使用短名。copyOf 的第二参数是新长度，本课用原长度；若改成2，只复制前两项，若改成4，多出的 int 项默认0。

这里复制的是基本类型 int 值。对装引用的数组，复制元素仍可能让两份数组中的引用找到同一对象，叫浅拷贝；本课项目先用 int，不要求提前实现任意深拷贝。

## 5. 遍历：循环替你依次选中元素

**遍历**就是按一定顺序访问这一组数据。下标循环让 i 依次取0、1、2：

```java
public class ArrayLoopWalk {
    public static void main(String[] args) {
        int[] scores = {70, 80, 90};
        int sum = 0;
        for (int i = 0; i < scores.length; i++) {
            sum += scores[i];
            System.out.println("i=" + i + ", sum=" + sum);
        }
        for (int score : scores) {
            score++;
        }
        System.out.println("first=" + scores[0]);
    }
}
```

| i | 访问 | 进入 sum | 离开 sum |
|---:|---|---:|---:|
| 0 | scores[0]=70 | 0 | 70 |
| 1 | scores[1]=80 | 70 | 150 |
| 2 | scores[2]=90 | 150 | 240 |
| 3 | 条件假，不访问 | 240 | 240 |

**增强 for**写成 `for(元素类型 临时变量 : 数组)`，依次把元素值交给临时变量。此处 score 是 int 副本，score++没有写回数组，所以最后 first=70。要修改 int 元素，应通过下标，例如 scores[i]++。

不要把这条结论无限扩大：若元素是对象引用，临时变量得到引用副本，仍可能通过它修改共享对象；本课只针对 int 成绩讨论。

## 6. 排序会动谁，查找返回什么

**排序**将元素按规则排列。`Arrays.sort(scores)`直接修改传入数组；若需要保留录入顺序，先复制，再排序副本。

```java
import java.util.Arrays;

public class SortCopyWalk {
    public static void main(String[] args) {
        int[] original = {90, 0, 60};
        int[] sorted = Arrays.copyOf(original, original.length);
        Arrays.sort(sorted);
        System.out.println("original=" + Arrays.toString(original));
        System.out.println("sorted=" + Arrays.toString(sorted));
        System.out.println("index=" + Arrays.binarySearch(sorted, 60));
    }
}
```

输出 original=[90, 0, 60]、sorted=[0, 60, 90]、index=1。这里的1是60在排序后数组中的下标，不是成绩，也不是原数组中的位置。

**二分查找**利用有序数据每次缩小范围。Arrays.binarySearch 的前提是相应区间按同样规则有序；不能对未排序数据调用后，把偶然结果当保证。未找到返回负数编码，不一律等于−1。当前先会辨别找到与否，插入点编码可到教材深化时研究。

## 7. 二维数组：一组行，每行又是一组元素

```java
public class RaggedWalk {
    public static void main(String[] args) {
        int[][] rows = {{1, 2}, {3, 4, 5}, {}};
        int total = 0;
        for (int row = 0; row < rows.length; row++) {
            int rowSum = 0;
            for (int col = 0; col < rows[row].length; col++) {
                rowSum += rows[row][col];
            }
            total += rowSum;
            System.out.println("row=" + row + ", sum=" + rowSum);
        }
        System.out.println("total=" + total);
    }
}
```

输出各行合计3、12、0，总计15。画成：

```text
rows ──> 第0行引用 ──> [1][2]       长度2
         第1行引用 ──> [3][4][5]    长度3
         第2行引用 ──> 空数组        长度0
```

**不规则数组**就是这些行长度可以不同。外层 rows.length 是行数；内层每次读 rows[row].length，不能固定用第0行的长度处理所有行。

行合计 rowSum 在每次外层进入时清零；总计 total 只在所有行之前清零一次。第三行长度0，内层零次，行合计仍0。若某一行是 null，则连行长也不能读；本题给的是空行，不是 null 行。

## 8. 课程原创统计项目，先写六个小阶段

原练习 ScoreStats 的输入和输出是合同，先读懂再写。**算法**在这里是为完成任务安排的一串明确步骤，不必先会高深数学。

| 阶段 | 先做到什么 | 此时怎样验证 |
|---|---|---|
| 1 | 固定数组 {59,60,90,100}，只求总分 | 应为309 |
| 2 | 加最大、最小、及格人数 | 应为100、59、3 |
| 3 | 加平均值并两位小数输出 | 应为77.25 |
| 4 | 先读n，再读n项，保存数组 | 打印原顺序，与输入逐项核对 |
| 5 | 在访问首项之前处理非法n和0 | −1/101为invalid count；0为no data |
| 6 | 复制排序，输出两份顺序 | 用90、0、60检查原顺序保留 |

可以先用阶段1的固定数据把统计写稳，再接输入。最终程序虽然把空数据检查放前面，学习时仍可以从最小普通案例搭建。

### 8.1 总和、极值、计数各保存什么

非空数组的最大和最小值可以从首元素初始化。不能假设所有任务都有正数，更不能把最大值固定设成0当万能模板。

```text
sum=0；maximum=scores[0]；minimum=scores[0]；passed=0
逐个成绩：
    加进 sum
    若比 maximum 大，更新 maximum
    若比 minimum 小，更新 minimum
    若至少60，passed加1
```

对59、60、90、100追踪：

| 当前成绩 | sum | maximum | minimum | passed |
|---:|---:|---:|---:|---:|
| 初始 | 0 | 59 | 59 | 0 |
| 59 | 59 | 59 | 59 | 0 |
| 60 | 119 | 60 | 59 | 1 |
| 90 | 209 | 90 | 59 | 2 |
| 100 | 309 | 100 | 59 | 3 |

### 8.2 平均值在哪一步需要 double

`sum/n`两边若是 int，会先丢小数。使用 `sum/(double)n`，再用 Locale.US 和 %.2f 输出。格式化不能救回已经算成77的整数除法结果。

### 8.3 没有数据，先结束再碰首元素

n=0 时没有 scores[0]，也没有通常意义上的最大、最小和平均值。本题规定只输出 no data 并结束。用 return 结束 main：

```text
读 n
如果不在0–100：输出 invalid count，return
如果 n==0：输出 no data，return
再创建、读取并统计数组
```

return 在这里结束当前 main，不是循环的 continue。把这两条检查放到访问首项之后，就来不及保护空数组。

题目保证后续有足够且有效的成绩。本阶段不用额外设计字母恢复或反复重输，也不能因为参考程序没做这些，就误判它违背题目的有效输入约定。

## 9. 命令行参数，也是一种数组入口

main 的 String[] args 装的是启动时传入的文本。不给参数，args.length 为0；有两项时合法下标为0、1。访问 args[0]前应先检查长度，否则零参数会越界。

原示例 ArgsEcho 让你观察这个区别。它与 Scanner 的键盘输入分开：前者启动时给，后者运行途中读。不要把程序暂停等待输入与数组参数为空混在一起。

## 对齐3.10.2：有初值的声明，与重新赋值分开

`int[] scores={70,80};`可以在声明时直接建立数组；已有变量后想换成新数组，要写`scores=new int[]{90,100};`，不能只写`scores={90,100};`。**匿名数组**是当场建立、不必先另取变量名的数组对象，不是没有类型或不受边界检查。

创建`new String[3]`时，三项初值是null，不是三个空字符串；`new boolean[3]`的初值为false。数组对象存在，不表示每项引用所指对象已经建立，读取names[0].length()前还要有实际String。

3.10.4特别区分：args[0]是第一项用户参数，不是程序名或java工具名。启动`java Demo red blue`时，数组两项是red、blue，这与部分其他语言的约定不同。

## 对齐3.10.5：抽取不重复项，看“有效范围”如何缩小

教材的随机抽取案例核心不在排序本身，而在于抽过的值不能再次进入选择范围。用一份原创的座位选择小例子手走：候选[1,2,3,4,5]，有效项数5；选中下标1得到2；把最后有效项5搬到位置1，再把有效项数减为4。

```text
抽取前：[1][2][3][4][5]  有效范围0–4
抽到2后：[1][5][3][4] | [5]  仅左边0–3参与下一轮
```

数组长度仍是5，变化的是“尚可选择的有效数量”；右边留下的旧值不再参与，不等于它会被自动清零。再抽时只从当前有效下标中选，才不会重复取回2。

Math.random得到[0,1)内的值，乘正的有效数量再转int，可以得到0到数量−1的下标。不要把“随机下标”与“数组中的值”混为一谈。本课统计项目不需要随机抽取，这段作为教材案例桥梁，不新增必交题。

Arrays除了sort/copyOf还提供fill、equals、copyOfRange等工具。数组引用的==不逐项比内容；Arrays.equals可以对本课一维int数组比较对应元素。copyOfRange同样采用起点含、终点不含。

## 对齐3.10.6–3.10.7：矩形表和逐行创建

`new double[2][3]`建立两行、每行三项的数组；教材复利表中一维表示年，一维表示利率，后一年的对应项读取前一行同列，再计算增长。原书允许按需要回读多维部分，本课提供RaggedWalk帮助先掌握两层访问，具体金融表格作深化。

若写`new int[3][]`，只建了保存三条行引用的外层，行引用初值null；还要分别`rows[0]=new int[1]`等，才能访问各行元素。与`{{1,2},{3,4,5},{}}`直接把行都建好的情况不同。

```text
外层新建后：第0行→null，第1行→null，第2行→null
分配各行后：第0行→长度1，第1行→长度2，第2行→长度3
```

教材的三角组合数表正好每行需要不同长度。换一行数据可以只改行引用；例如用一个int[]临时变量交换rows[0]与rows[1]，不需要逐个交换所有元素。

增强for遍历二维数组时，一次取到一行int[]，不是自动逐个取出全部int；因此仍需内层循环。快速显示整张表可查Arrays.deepToString。

**API核对提醒**：书本p84–85 / PDF p102–103把type[]说明得过于统一；不能据此推断Arrays.sort和binarySearch也接受boolean[]。本课程序都用已核对的int[]入口，查方法时仍须看真实重载类型。

原有[独立示例及命令](code/README.md)可以在学过相应小节后对照。完成以后再看[参考答案与解析](参考答案/答案.md)，寻找自己的思路与参考思路第一次不同的地方。材料编译通过不代表学生过关；作答仍需单独批改并保存到[进度追踪](../学习进度模板.md)。
