## 困惑：类写在另一个类里面，外面的每个对象就自动带一个吗

不会。**嵌套**先是声明位置关系，是否创建对象仍看new。非static成员内部类的对象还关联一个外围实例，可访问其状态；static嵌套类没有这种隐含外围实例。像馆内读者证关联某一间图书馆，而通用“最小最大值结果卡”只按名称归图书馆管理、不依附某一馆的当前库存。边界是Java不会按现实容器自动分配内部对象；引用关联也不保证外围对象永远只有一个内部对象。

```java
public class MemberRooms {
    private final String title;
    MemberRooms(String title) { this.title = title; }
    class Reader {
        private final String title = "读者";
        String display() { return this.title + "/" + MemberRooms.this.title; }
    }
    static class Range {
        private final int min, max;
        Range(int min, int max) { this.min = min; this.max = max; }
    }
    static Range minmax(int[] values) {
        if (values.length == 0) throw new IllegalArgumentException("empty array");
        int min = values[0], max = values[0];
        for (int value : values) { min = Math.min(min, value); max = Math.max(max, value); }
        return new Range(min, max);
    }
    public static void main(String[] args) {
        MemberRooms east = new MemberRooms("东馆");
        Reader reader = east.new Reader();
        System.out.println(reader.display());
        Range range = minmax(new int[] {7, 2, 9});
        System.out.println(range.min + ".." + range.max);
    }
}
```

输出`读者/东馆`、`2..9`。main先new一个MemberRooms外围对象，再`east.new Reader()`创建关联它的Reader；不是`new MemberRooms.Reader()`随便跳过外围实例。Reader中的this.title是自己的“读者”；MemberRooms.this.title明确沿外围引用取“东馆”。两者都叫title，语法限定才能让归属清楚。

Reader可直接访问外围private成员，这是词法嵌套赋予的访问能力，不需要为它特意暴露public getter。换到另一个普通顶层类，不会自动享有同样权限。也不要把它理解为Reader继承MemberRooms；它没有extends，二者不是is-a。

| 引用 | 指向 | 如何取得状态 |
|---|---|---|
| east | MemberRooms实例A | A.title东馆 |
| reader | Reader实例B | B.title读者 |
| B的外围关联 | A | MemberRooms.this.title |
| range | Range实例C | min2/max9，无隐含A |

## 静态嵌套类：归属名称，不绑定外围实例

`static class Range`仍是可new的类，static并不是说“只能有一个Range对象”。它意味着创建Range不需要先有MemberRooms实例，也没有MemberRooms.this可用。minmax是static方法，只操作传入数组，返回Range；其中保存min/max，不依赖某个馆。调用者可用MemberRooms.Range限定名称。本例main位于同一外围类，能访问其private字段，不能据此推断外部所有代码也能直接读。

minmax要求非null且非空。先用第一个元素初始化极值，再遍历；空数组没有最小值，我们用IllegalArgumentException明确拒绝，throw的读法见L24，正式异常课再补。只遍历一次求两端，比用两个完整循环更直接；一个结果对象返回两个值，不意味着Java方法有两个返回槽。

## 局部类和匿名类：缩小名字的使用范围

后文LocalActionForms把一个类写进make方法，只有那个块内能用它的类名；对象可以通过Runnable接口返回，离开方法后照样执行。它捕获suffix的值，局部参数必须final或事实上final，和Lambda同样不能重绑。返回对象不等于局部类名也泄漏到外部作用域。

`new Runnable() { ... }`后面多出的类体表示创建一个实现接口的匿名类实例，不是直接实例化接口。没有自己的类名，所以不能写同名构造器；实现接口时括号里没有构造参数，继承某个类时可把参数交给父构造器。匿名类有自己的this；Lambda沿用外围this，这是两者不能机械互换的重要差别。只实现函数式接口且无额外状态时通常Lambda更清楚，需要额外字段/不同this时仍可用匿名类。

“双括号初始化”外层是匿名子类体、内层是实例初始化块，不是新的集合字面量。它会额外创建子类，还可能关联外围对象、影响严格getClass相等规则；本课程添加集合用普通构造和add，读到旧写法时再按这两层拆开。

## 文件结构与Java8语法边界

本课单个.java会生成MemberRooms.class及带$的嵌套类文件，一起才构成程序，不要只拷贝启动类class。JAR工具会一起装入，启动仍选有main的顶层MemberRooms，不把文件名MemberRooms$Reader当课程常规入口。若在PowerShell把带$的类名写入命令，单引号可避免变量展开；不是在Java包名里写反斜杠目录。

教材展示this$0或access$...等编译器合成细节，帮助理解实现，不能把具体名字当稳定API。本课程--release8目标下按Java8限制：非static内部类不能任意声明静态成员，允许常量变量；static嵌套类不受这条限制。较新Java放宽了一些语法，不拿教材旧规则冒称所有版本永恒限制；当前基础作业保持8兼容。

## 局部、匿名与Lambda的this对照

make返回时，局部类名字Local不再能被调用者直接使用，但返回的Runnable实例仍能执行；suffix捕获的值被保留，外围对象也仍被关联。这里不用静态main里的this，所有三种动作在实例方法forms内建立。

```java
public class LocalActionForms {
    private final String prefix = "外";
    Runnable make(String suffix) {
        class Local implements Runnable {
            @Override public void run() { System.out.println(prefix + suffix); }
        }
        return new Local();
    }
    void forms() {
        Runnable local = make("!");
        Runnable anonymous = new Runnable() {
            private final String prefix = "内";
            @Override public void run() { System.out.println(this.prefix + "/" + LocalActionForms.this.prefix); }
        };
        Runnable lambda = () -> System.out.println(this.prefix);
        local.run(); anonymous.run(); lambda.run();
    }
    public static void main(String[] args) { new LocalActionForms().forms(); }
}
```

输出`外!`、`内/外`、`外`。匿名类自己的prefix遮蔽外围字段，必须LocalActionForms.this.prefix才明确取外；Lambda中的this直接就是LocalActionForms实例。只改make("!")为make("?")，仅首行变化。若在make里重绑suffix，局部类捕获不再合法，和Lambda一样会编译失败。

在课程根目录PowerShell运行`./java.ps1 -Source './L28_第06章D_内部类与所属对象/code/LocalActionForms.java'`。

## 两个外围实例：内部对象究竟关联哪一个

“Card写在School里”只回答声明归属，`one.new Card()`才指定这张卡关联one学校。像两家分馆各自发证，卡不是查询某个全局“当前分馆”；类比边界是外围关联是Java对象引用关系，不是磁盘目录嵌套。

```java
public class TwoOuterLinks {
    private final String title;
    TwoOuterLinks(String title) { this.title = title; }
    class Card { String label() { return TwoOuterLinks.this.title; } }
    public static void main(String[] args) {
        TwoOuterLinks one = new TwoOuterLinks("青禾");
        TwoOuterLinks two = new TwoOuterLinks("海风");
        Card a = one.new Card();
        Card b = two.new Card();
        Card alias = a;
        System.out.println(alias.label());
        System.out.println(b.label());
        System.out.println(a == alias);
    }
}
```

Card没有自己保存title，label读取词法外围实例的title；读作TwoOuterLinks.this.title最明确。a和b虽然同属Card类型，关联的外围对象不同。把a引用赋给alias只增加别名，不会改学校。

状态图：one→外围A[青禾]，a/alias→卡C→外围A；two→外围B[海风]，b→卡D→外围B。只改two的标题，第二行变，第一行不变。独立任务：再用one.new Card建立第三张卡，说明是“同一外围、不同内部对象”；外围对象的数量与内部对象的数量不需要相同。static Result则没有这条隐含外围关联，但照样可new多个。

运行现成示例：在课程根目录PowerShell输入`./java.ps1 -Source './L28_第06章D_内部类与所属对象/code/TwoOuterLinks.java'`。改动先复制到my_code，命令相应替换目录。
