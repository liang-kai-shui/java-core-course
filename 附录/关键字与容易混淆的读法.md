# 关键字与容易混淆的读法

> 教材附录A：**书本 p710–711 / PDF p728–729**。本页是课程原创的查阅与辨析，按用途组织；不要把背完整张表作为入门门槛。正文第14章结束在书本 p709 / PDF p727，p710已经是附录。

遇到陌生词，先问它在声明、表达式还是控制流程里，再回对应讲义跑程序。关键字像语法里的固定路标，变量名、类名像你给地点起的名字；类比边界是同一个词在不同语法位置可承担不同作用，不能只靠汉语翻译猜整句含义。

## 声明与结构：先问谁属于谁

| 词 | 当前可用读法 | 容易误会的边界 |
|---|---|---|
| class | 声明一种类 | 不等于一个对象或一个进程 |
| interface | 声明接口契约 | 接口引用仍可指向实现对象 |
| enum | 声明有限的一组命名实例 | 不是任意整数的自动别名 |
| package | 当前编译单元所属的名字空间 | 源码根不写进包名；包不是JAR |
| import | 为源码中的类型名字提供短写规则 | 不复制文件，不替代classpath |
| extends | 类继承父类、接口继承接口；泛型处还表达上界 | 要根据位置读，不能一律说“创建父对象” |
| implements | 类承诺实现接口 | 不意味着自动注册进ServiceLoader |
| abstract | 类不能直接实例化，或方法只声明要求 | 抽象类仍可有字段、构造器和完整方法 |
| new | 创建对象/数组并得到引用 | 不把类文件复制成新的字节码版本 |
| this | 当前实例；this(...)委托同类构造器 | static上下文没有当前实例可用 |
| super | 按规则访问父类成员或调用父类构造器 | 不是另一个可随意赋值的父对象变量 |
| static | 成员归类；静态内部类不隐含外部实例 | 不等于常量、线程安全或自动全局可访问 |
| final | 变量不能再次赋值、方法不可覆盖、类不可继承 | final引用仍可能指向可变容器 |

这些词对应S01–S06及第4–6章。判断`ReaderCard.class`时，Java表达式里的`.class`取得Class对象，文件管理器中的`ReaderCard.class`则可能是字节码文件名；字符相同，语境不同。

## 可见性：允许写出名字，还要看接收者和上下文

public、protected、private控制访问边界；不写这三者时，成员通常为包访问。protected的跨包子类访问还有接收者限制，不是“只要继承了，拿任意父类对象都能访问”。private也不适合背成“只有同一个对象能看”：访问权限按类型与相关语言规则判断，同类方法可以读取另一个同类实例的私有字段。详细实验见L17、L20。

## 类型与方法结果：数值范围、返回值与打印分开

| 一组词 | 读法 |
|---|---|
| byte、short、int、long | 不同范围的有符号整数类型；中间运算提升与溢出仍要检查 |
| float、double | 浮点类型；有限精度，不保证十进制小数都精确 |
| char | 一个UTF-16代码单元，不保证正好是一个完整可见字符 |
| boolean | true/false两种布尔值，不把整数当条件 |
| void | 方法不交回结果值；不代表不产生副作用或不打印 |
| return | 结束当前方法，必要时交回结果；不是“打印到屏幕” |
| instanceof | 按类型关系检查对象；对null的普通检查结果为false |

true、false是布尔字面量，null是空引用字面量，**不是关键字**；不能用作普通标识符。String、System、main、Scanner、var在不同版本中的角色也不能只因常见就统称Java8关键字。Java区分大小写，String是类名，string不是同义关键字。

## 流程：条件、循环与跳转各管哪一段

if/else作条件选择；switch/case/default作分支选择。Java8传统switch注意break与贯穿；default还可用于接口默认方法，必须按上下文辨认。

while先检查、do...while至少先执行一次；for把初始化、条件、更新写在一处，也有增强for遍历。break跳出指定循环或switch，continue进入下一次循环的相应检查/更新，不等于退出方法；return才结束当前方法。goto、const在Java8保留但没有相应可用语句，不能拿来当变量名。

用L08/L09的执行路线回答三个问题：跳的是哪个结构、下一条执行哪里、哪一个状态更新会被跳过。只背“break跳出、continue继续”不足以预测嵌套程序。

## 异常：声明可能失败，与这一次真的抛出分开

try划定受处理或资源管理的范围，catch接住匹配异常；throw是这次抛出一个Throwable对象，throws是方法声明可能传播哪些受查异常。finally用于离开相关控制路线时的清理安排，不能承诺强行终止JVM、系统崩溃等情况下仍执行；不要在finally return覆盖原结果/异常。assert检查开发假设，可能未启用，不能代替必需的用户输入验证。

下面是**语法片段，不能独立编译运行**，完整程序见L30–L32：

```java-fragment
int readCount(String text) throws NumberFormatException {
    return Integer.parseInt(text);
}
```

`throws`没有在这一行制造异常；真正解析到非法字符串时，调用链才发生失败。NumberFormatException属于非受查异常，这里可以声明但不要求必须声明；不要从这个例子推出“所有throws都必须被调用者catch”。

## 并发：别把修饰符当整个对象的安全证书

synchronized对同一监视器建立互斥与可见性约定，不禁止CPU调度切换，不自动保护绕过锁的访问，也不自动回滚半次业务更新。volatile提供字段读写的可见性/有序性规则，不把`count++`合成一次原子操作。final字段初始化规则也不把其指向的HashMap变成并发容器。请用L51/L52的完整程序分辨。

native声明方法实现由本地代码提供，不是“Java网络方法”。transient控制默认对象序列化时是否保存实例字段，不等于该字段不占内存、不持久也不保证秘密不会泄露；本书更完整的序列化/本地方法内容位于卷Ⅱ，本课程不把它们伪装成已系统讲完的卷Ⅰ主题。

## 版本读法：本课Java8目标与JDK21运行要同时看

strictfp在旧语言版本用于约束浮点求值规则，JDK17起恢复始终严格的浮点语义，新增strictfp已无同样必要，见[JEP 306](https://openjdk.org/jeps/306)。不能从教材短表推出它会让浮点变成精确十进制。

Java8与新Java的保留/上下文关键字集合不同，例如单独下划线在较新版本已不能作为普通标识符；record、sealed、var等也涉及版本和语法位置。本课普通源码保持Java8语法/API，用JDK21的--release 8编译。查关键字时先确认源码目标版本，别把较新写法抄进本课再怀疑自己连基本类结构都没懂。
