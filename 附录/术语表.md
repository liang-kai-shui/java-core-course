# 术语表 · 先懂作用，再记名称

| 词 | 一句话解释 | 为什么需要／类比 |
|---|---|---|
| 编译 | 将源码检查并转换为另一种可执行表示 | 像先检查配方并翻译成执行清单；不保证配方符合你的本意 |
| 字节码 | Java编译器常见的输出指令格式 | 交给JVM执行；不是本机CPU直接执行的全部机器码 |
| JVM | 执行Java字节码的虚拟机 | 各平台安装合适的执行环境 |
| JDK | Java开发工具包 | 含javac、java等，像开发工具箱 |
| 类 | 一种程序组织与对象描述方式 | 当前先作为程序外壳；第4章展开 |
| 对象 | 按某个类建立的具体实例 | 类像说明，具体对象像按说明制作的一份物品 |
| 方法 | 类中有名字、可以被调用的一段操作 | 避免每次重新描述操作；第4章系统讲定义 |
| main | 当前命令行程序的启动入口方法 | JVM启动这个类时从它开始 |
| 变量 | 类型、名字和值之间的一种绑定 | 给运行中的数据起名；不是数学里永不改变的等号 |
| 类型 | 规定值的种类和允许的操作 | 防止把不合适的东西混用；有些错误能编译前发现 |
| 字面量 | 源码中直接写出的值 | 如42、3.5、'A'、"hi"、true |
| 表达式 | 能计算出一个结果的组合 | 如price*count，用计算结果参与更大任务 |
| 引用 | 用于访问对象的值 | 类比找到对象的凭证；不是C++可做地址算术的指针 |
| null | 引用没有指向对象的特殊值 | 不等于空字符串或长度为0的数组 |
| 索引／下标 | 指出序列中的第几个位置 | 从0开始，像一排格子的编号 |
| 异常 | 程序运行过程中报告异常情况的机制 | 如访问不存在的位置；不等于所有错误 |
| API | 库提供给调用者使用的功能约定 | 像工具说明：名字、参数、返回值和限制 |
| 作用域 | 代码中一个名字可以被使用的范围 | 不是对象在内存中存活多久 |
| 边界测试 | 专门检查最小、最大、刚好临界的情况 | 常能发现平常输入隐藏的问题 |
| UTF-8 | 把文字编码成字节的一种方式 | 保存、读取双方使用一致规则才能正确显示 |

遇到讲义里没有解释的新词，可以直接指出。术语表作为查阅补充，不能替代讲义第一次出现该词时的解释。
