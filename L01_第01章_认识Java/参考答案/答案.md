# L01 参考答案 · 先独立作答

本文件是课程原创参考，允许其他正确解法。代码与参考答案通过验证不等于学生已通过。

Q1：源码是人写的程序文本，javac检查并编译为class中的字节码，JVM在运行环境中执行。Q2：编译通过不保证题意和算法正确；执行还需要兼容运行环境及依赖。

E1：姓名可不同，必须有两行且第二行文字符合题意。看真实源码、命令和输出。E2：记录本机值，不要求和助手版本相同；JDK与操作系统可能不同。E3：少分号应先在编译阶段失败；恢复后必须重新编译再运行。没有运行证据时保留待验证，不因能复述答案就判全课通过。
