## 这一课要解决什么问题

同样的程序，需要按年龄或分数选择不同操作。怎样写出互斥又没有漏掉临界值的规则？

## 1. if是按条件选择执行

**条件**是计算结果为boolean的表达式，像一道决定往哪走的路口。`if (score >= 60) { ... } else { ... }`只选一个分支。条件不是任意整数；`if(1)`不能照搬到Java。

```java
if (score < 0 || score > 100) {
    System.out.println("invalid");
} else if (score >= 90) {
    System.out.println("excellent");
} else if (score >= 60) {
    System.out.println("pass");
} else {
    System.out.println("retry");
}
```

这是一条互斥的条件链：前一项成立就不再测试后面的项。顺序是规则的一部分；先测`>=60`再测`>=90`，90分也会先进入pass。多个独立if不是同一回事，可能重复打印。

## 2. 先写范围表再写代码

把分数切成：小于0、0–59、60–89、90–100、大于100。分界处用-1、0、59、60、89、90、100、101验证。**边界测试**就是专门在这些接缝检查，像检查两块拼图之间有没有缝或重叠；只测75分无法证明60分正确。

判断“18至25岁，包含两端”，写`age >= 18 && age <= 25`，不能写数学式`18 <= age <= 25`。同类条件先用括号表达清楚，不要依靠缩进猜关联。

## 3. 代码块与作用域

**代码块**是花括号包围的一组语句。局部变量通常从声明后到所属块结束可用，块里的同名声明还有限制。写入块内不等于声明了一个到处可用的名字。

```java
if (ready) {
    int count = 3;
    System.out.println(count);
}
```

块外用count会编译失败。初学时总给分支加花括号，避免只控制一条语句时误读。不在if括号后随手加分号：`if(condition);`可能让后面的语句无条件执行。
