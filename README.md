本课程沿用 C++ 学习项目的方式：先用白话解释一个知识点解决什么问题，再精读教材、手敲示例、改参数观察现象、完成练习，最后由 AI 批改并持续记录进度。不假设你已经会 C++，也不根据“以前看过”推定已经掌握。

## 如果你对电脑操作也不熟

先读[《零基础起飞》](附录/零基础起飞.md)。它从电脑、文件、扩展名、路径讲起，带你打开任务管理器和PowerShell、新建源码、编译运行、观察class文件，再处理中文和旧结果问题。每个阶段都有具体操作、应看到的结果及排错办法，可以分几次完成。

第一次出现的名词，先说清“是什么、为什么需要、可以怎样类比”，再用操作建立认识。类比只帮助理解，不能替代真实规则；不能把“写一行定义”当作已经教会，也不把任务管理器、当前位置、保存等电脑操作默认为人人会。

## 怎样使用

1. 第一次先读 [零基础起飞](附录/零基础起飞.md)、[环境说明](环境说明.md) 和 [页码对应说明](页码对应说明.md)。
2. 每课先读讲义的“要解决的问题”，按双页码表精读或略读教材。
3. 在 `my_code/` 里新建文件手敲示例，先预测结果再运行；保留原 `code/` 示例。
4. **直接在每课的 `练习.md` 里写答案，按 `Ctrl+S` 保存。** 代码写入 `my_code/`，在题目下记录源码路径、命令和结果；不必另建 `作答.md`。已有作答文件仍可继续使用。
5. 完成后告诉 AI 课号并提供作答；AI 先读 [进度追踪](学习进度模板.md)，按 [批改指南](给其他LLM的批改指南.md) 批改。
6. 按提示订正，复核通过后进入下一课。参考答案在各课 `参考答案/`，先独立思考再看。

本书不是按章配置成套习题的入门课本，因此本项目练习均为原创配套题，**不是教材原题或官方答案**。

本地个人练习与公开课程分开维护：本地 `练习.md` 保留你的答案；公开网页、压缩包和GitHub发布目录从独立的空白题目模板构建，不会因为重新打包而清掉答案，也不会把你的作答混入公开习题。

## 快速运行一个示例

在本目录打开 PowerShell：

```powershell
.\check-java.ps1
.\java.ps1 -Source '.\L01_第01章_认识Java\code\HelloJava.java'
```

若当前进程的脚本执行策略阻止运行，可用以下单次命令，不改系统执行策略：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\java.ps1 -Source '.\L01_第01章_认识Java\code\HelloJava.java'
```

VS Code直接打开整个 `D:\Code\Java` 文件夹，打开一个本课程独立 `.java` 文件后按 `Ctrl+Shift+B`，调用项目任务。别把PDF当作工作区，也别只打开父目录后套用其他项目的运行配置。

本机检测到 GraalVM JDK 21.0.12；命令行PATH未找到 `java`/`javac`。项目脚本优先读取 `.java-course.json`，不修改全局环境。示例采用 Java 8 语法/API，在本机 JDK 21 上以 `--release 8` 编译。`java.ps1`面向当前无package的单文件程序；后续多文件工程会另设运行入口。

## 学习纪律

先自己写、先预测、再运行。报错保留从第一行开始的完整文本。提交时写明输入、期望、实际结果。卡住时先写出思路，AI默认给提示；你明确需要完整答案时可以直接说明。

不要因为见过C++的相似写法就跳过验证：Java的boolean、字符串比较、数组引用和按值传参都有自己的规则。
