## 学完要能做什么

能分清模型内容与显示；用布局嵌套组织表单；独立读文本、拒绝空输入，选择复选/单选/下拉/滑块并解释各自状态。

## 文本框只显示一截，内容是不是被删掉了

界面有三类职责：**模型**保存内容/状态，**视图**把它呈现出来，**控制器**解释输入并操作模型或视图。像同一份成绩登记可以显示完整明细或统计图，翻动窗口不等于删除登记；类比边界是Swing不要求每个部件都严格分成三个你亲手new的对象，实际常合并视图与控制的职责。

JTextField包装文本模型与呈现，getText/setText访问内容，列数只是首选宽度提示，不限制可输入长度；光标移动/水平滚动不等于文本变少。JButton模型保存按下/启用/选中等状态，不保存全部外观文字和图标；不要从按钮getModel想当然取得所有UI信息。设计模式是经验组织方式，不是照名词硬凑三个空壳类。

## 第一张能独立使用的输入表

```java
import java.awt.BorderLayout;
import java.awt.EventQueue;
import javax.swing.JButton;
import javax.swing.JFrame;
import javax.swing.JLabel;
import javax.swing.JPanel;
import javax.swing.JScrollPane;
import javax.swing.JTextArea;
import javax.swing.JTextField;
public class CourseEntryForm {
    static class Entry {
        final JPanel panel = new JPanel(new BorderLayout(8, 8));
        final JTextField field = new JTextField(12);
        final JTextArea area = new JTextArea(5, 24);
        final JLabel status = new JLabel("ready");
        final JButton add = new JButton("添加");
        Entry() {
            JLabel label = new JLabel("课程名"); label.setLabelFor(field);
            JPanel row = new JPanel(); row.add(label); row.add(field); row.add(add);
            area.setEditable(false); area.setLineWrap(true); area.setWrapStyleWord(true);
            panel.add(row, BorderLayout.NORTH); panel.add(new JScrollPane(area), BorderLayout.CENTER); panel.add(status, BorderLayout.SOUTH);
            add.addActionListener(e -> submit()); field.addActionListener(e -> submit());
        }
        void submit() {
            String title = field.getText().trim();
            if (title.isEmpty()) { status.setText("empty"); return; }
            area.append(title + "\n"); status.setText("added");
        }
    }
    public static void main(String[] args) throws Exception {
        if (args.length > 0 && args[0].equals("--check")) EventQueue.invokeAndWait(() -> {
            Entry entry = new Entry(); entry.field.setText("  数组  "); entry.add.doClick(0); entry.field.setText("  "); entry.add.doClick(0);
            System.out.println(entry.area.getText().replace("\n", "|")); System.out.println("status=" + entry.status.getText());
        }); else EventQueue.invokeLater(() -> {
            JFrame frame = new JFrame("课程输入"); frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); frame.add(new Entry().panel); frame.pack(); frame.setLocationByPlatform(true); frame.setVisible(true);
        });
    }
}
```

无参数显示课程名输入框、添加按钮和记录区。输入含空格课程名后按添加或在文本框回车，trim去两端普通空白，空串只显示empty，不加入记录；非空追加整行。JLabel说明字段并用setLabelFor关联输入框，按钮文字不能代替输入框的标签。

Entry本身是普通对象，持有panel/field/area等组件；没有为了保存这几个引用就继承JFrame。panel用BorderLayout，顶部row用JPanel默认FlowLayout排列标签、输入、按钮，中心JScrollPane包装JTextArea。滚动条由滚动窗格管理，不是JTextArea自动自带。记录区setEditable(false)禁止用户编辑，程序仍能append。

| 输入/动作 | 模型读取 | 业务选择 | 结果 |
|---|---|---|---|
| "  数组  "添加 | 原文本含空格 | trim后非空 | 追加数组和换行 |
| "  "添加 | 原文本是空格 | trim后空 | 状态empty，记录不变 |
| 文本框回车 | 同样getText | 调同一submit | 与按钮规则相同 |

--check用setText和doClick走同样处理，输出记录正文替换换行为竖线的数组|与status=empty。竖线仅诊断显示，实际area内保存的是换行。程序没有写磁盘文件，关窗口后记录不会自动保存。

只把field列数12改4，再输入长标题，内容仍可完整读取；变化的是显示宽度提示。独立任务：增加清空记录按钮，只清area而不改变正在输入的课程名；说明两个模型各自保存什么，别把“清空当前输入”和“清空已记录”混为一项。

## 布局管理器决定位置，组件自己给首选尺寸

FlowLayout按流排列，空间不够可折行，通常不拉伸每个按钮。BorderLayout五区每区放一项，中心占剩余；同一区连续加两按钮不会自动排成两项，先建子面板装按钮再放该区。北/南常保留首选高度但宽会随容器变，东/西常保留首选宽但高度会变，不能把教材p477“边缘尺寸不变”理解成两个维度都固定。

BorderLayout约束用常量，别手写全大写字符串；常量实际文本含大小写，源码里的常量名与字符串内容不是一回事。GridLayout按行优先放等大单元，一维可0表示推算，不能行列都0；若rows非0，实际列数按组件数量与行数推算。组件只有一个父容器，反复add到另一处是移动，不是自动复制。

布局变更后revalidate请求重算，repaint请求重画，pack重算顶层合适尺寸；三者职责不同。普通表单先用嵌套布局，不用setLayout(null)手写每项固定坐标躲开文字/缩放问题。下一课再讲复杂约束。

## 文本区、密码域与模型边界

JTextArea行列也只给首选尺寸。setLineWrap(true)是视觉折行，不往文档插入\n；setWrapStyleWord(true)尽量按词界，否则可按字符折行，**不是截掉文档正文**，教材p487 / PDF p505的“截断”不能当丢数据。getText取得完整模型，append才真正追加内容。

JPasswordField.getPassword返回char[]，用后可Arrays.fill覆写这份数组，并按业务需要清控件模型；遮住字符不等于加密，也不能照教材演示把密码new String再追加到公开文本区。书本p485 / PDF p503将setEchoChar(0)说成恢复默认不准确：0会取消掩码、显示正文，应保存原echo再恢复，已核对[JPasswordField API](https://docs.oracle.com/javase/8/docs/api/javax/swing/JPasswordField.html)。本课只用固定demo文本观察长度与生命周期，不编造完整认证系统。

## 选择控件先按任务选，而非按哪个长得好看

JCheckBox适合独立开关，多项可以同时选；JRadioButton配ButtonGroup表达互斥，但ButtonGroup只组织选择，不负责把按钮放进画面，还须add进容器。getSelection返回ButtonModel，未选可能null；要从模型取业务标识，先setActionCommand稳定字符串，别依赖显示标签自动成为模型命令。

JComboBox<T>适合一组离散选项下拉选择；非编辑模式可先查索引>=0，再getItemAt取得T；编辑模式结果可能不在原选项列表，getSelectedItem是Object，不能盲信泛型元素类型。removeAllItems后无选择是正常边界，监听器应处理。ItemListener可能收到取消与选中两类事件，不能每次都当新增一次业务；只需当前选择时可在ActionListener中读取模型。

JSlider保存整数范围值，视觉拖动平滑不等于返回任意实数。ChangeListener.stateChanged读取getValue，拖动过程中可多次通知，昂贵工作可在getValueIsAdjusting为false时提交，但界面预览可实时更新。刻度间距是数值单位，setPaintTicks/Labels决定是否画出来；snapToTicks不意味着每次中间事件都已对齐。滑块当前值与显示标签也需要初始化一致，不等第一次事件才填。

边框由BorderFactory创建再setBorder，empty边框提供留白，titled提供分组说明，compound组合内外边框；不是额外的JPanel对象。以下独立程序逐项观察状态，再做原创表单，避免一开始用十几个控件掩盖读取规则。

## 两个文本框，一份Document：视图数量不等于数据副本

```java
import java.awt.EventQueue;
import javax.swing.JTextField;
import javax.swing.text.PlainDocument;
public class SharedTextDocument {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            PlainDocument model = new PlainDocument(); JTextField first = new JTextField(3), second = new JTextField(12);
            first.setDocument(model); second.setDocument(model); first.setText("A"); second.setText("AB");
            System.out.println(first.getText()); System.out.println(second.getText()); System.out.println(first.getDocument() == second.getDocument());
        });
    }
}
```

输出AB、AB、true。PlainDocument是无格式文本模型，两个JTextField都setDocument到它；从first设A再从second设AB，最终两视图都读到AB。它不是每次getText后自动复制到另一框，而是共享同一模型。列数3与12可不同，完整内容仍相同。

状态：共享模型空→first写A→模型A→second写AB→模型AB→两框读AB。只给second独立新PlainDocument，最终first A、second AB。独立解释窄视图滚动并不会截断模型，使用一个模型多个视图时也不该在Document通知处理中递归改同一文档。

## 互斥组不负责画面位置：两个选择层次分别看

```java
import java.awt.EventQueue;
import javax.swing.ButtonGroup;
import javax.swing.JCheckBox;
import javax.swing.JRadioButton;
public class IndependentAndExclusive {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JCheckBox bold = new JCheckBox("粗"), italic = new JCheckBox("斜"); bold.doClick(0); italic.doClick(0); System.out.println(bold.isSelected() + ":" + italic.isSelected());
            ButtonGroup group = new ButtonGroup(); JRadioButton small = new JRadioButton("小", true), large = new JRadioButton("大");
            small.setActionCommand("SMALL"); large.setActionCommand("LARGE"); group.add(small); group.add(large); large.doClick(0);
            System.out.println(small.isSelected() + ":" + large.isSelected()); System.out.println(group.getSelection().getActionCommand());
        });
    }
}
```

输出true:true、false:true、LARGE。两个复选开关可同时选；单选small先选，large.doClick后small取消；getSelection返回模型，显式setActionCommand后才读到业务码LARGE。ButtonGroup不在panel里显示任何部件，要为可见界面另add单选按钮到容器。

只删group.add(large)，二者可能同时选，说明互斥来自组管理，不是圆形外观。独立给另一组“阅读/练习”按钮单独ButtonGroup，验证不影响字号组；把所有按钮丢同一组会让不相关选项互相取消。不要把单选的唯一性误推广为必须总有选择，初始全未选或clearSelection后可能null。

## 下拉与滑块：值变化先读模型，空选择先守门

```java
import java.awt.EventQueue;
import javax.swing.JComboBox;
import javax.swing.JLabel;
import javax.swing.JSlider;
public class SelectionModelChanges {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JComboBox<String> mode = new JComboBox<>(new String[]{"阅读", "练习"}); JLabel selected = new JLabel("阅读");
            mode.addActionListener(e -> { int i = mode.getSelectedIndex(); selected.setText(i < 0 ? "none" : mode.getItemAt(i)); });
            JSlider slider = new JSlider(0, 100, 50); JLabel amount = new JLabel("50"); slider.addChangeListener(e -> amount.setText(Integer.toString(slider.getValue())));
            mode.setSelectedIndex(1); System.out.println(selected.getText()); slider.setValue(80); System.out.println(amount.getText());
            mode.removeAllItems(); System.out.println(selected.getText());
        });
    }
}
```

输出练习、80、none。组合框setSelectedIndex(1)会通知读取当前选择，先查索引；清空列表后索引-1显示none。滑块setValue80触发ChangeListener，把标签同步80；不依赖通知次数恰好几次，只检查最终模型与显示。

初始阅读/50由代码主动设置标签，避免等第一次用户操作。只把组合框设为editable，getSelectedItem可能是列表外文字，原getItemAt路径不再覆盖全部编辑输入；先重新规定编辑协议，不在同一实验偷偷强转。独立为滑块加刻度10与setPaintTicks(true)，说明10是数值距离，不是屏幕10像素。

在课程根目录PowerShell运行`./java.ps1 -Source './L43_第12章A_模型布局与输入控件/code/SelectionModelChanges.java'`。


## 密码内容、返回数组与掩码分别管理

```java
import java.awt.EventQueue;
import java.util.Arrays;
import javax.swing.JPasswordField;
public class PasswordArrayLifecycle {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JPasswordField field = new JPasswordField("demo", 8); char originalEcho = field.getEchoChar(); char[] chars = field.getPassword();
            System.out.println("length=" + chars.length); Arrays.fill(chars, '\0'); field.setText("");
            boolean cleared = true; for (char c : chars) if (c != '\0') cleared = false; System.out.println("cleared=" + cleared);
            field.setEchoChar((char) 0); System.out.println("masked=" + field.echoCharIsSet()); field.setEchoChar(originalEcho);
        });
    }
}
```

输出length=4、cleared=true、masked=false。样本仅使用固定demo值：getPassword返回四个字符，Arrays.fill清的是这份返回数组，setText清控件模型是另一操作。最后设置echo为0说明取消掩码，随后恢复保存的原echo。没有打印密码正文，也不将它转String加入日志。

只删field.setText("")，返回数组虽已清理，控件模型仍有原内容，说明两份状态不同。独立解释“屏幕是星号”只改变视图，不能证明模型为空或已加密。不要把这个内存生命周期样本当已经实现认证、存储或传输协议。

在课程根目录PowerShell运行`./java.ps1 -Source './L43_第12章A_模型布局与输入控件/code/PasswordArrayLifecycle.java'`。


## 布局改变的是部件矩形，不改业务文本

```java
import java.awt.BorderLayout;
import java.awt.EventQueue;
import javax.swing.JButton;
import javax.swing.JLabel;
import javax.swing.JPanel;
import javax.swing.JTextArea;
public class NestedLayoutSizes {
    public static void main(String[] args) throws Exception {
        EventQueue.invokeAndWait(() -> {
            JPanel root = new JPanel(new BorderLayout(4, 4)), south = new JPanel(); JTextArea center = new JTextArea(3, 10);
            south.add(new JButton("保存")); south.add(new JButton("取消")); root.add(new JLabel("标题"), BorderLayout.NORTH); root.add(center); root.add(south, BorderLayout.SOUTH);
            root.setSize(400, 200); root.doLayout(); int width = south.getWidth(), height = center.getHeight();
            root.setSize(600, 320); root.doLayout(); System.out.println("wider=" + (south.getWidth() > width)); System.out.println("centerTaller=" + (center.getHeight() > height));
        });
    }
}
```

输出wider=true、centerTaller=true。root边框布局中顶部标签、中心文本区、南部按钮面板；南部面板自身用FlowLayout。根从400×200改600×320并重新doLayout后，南部宽变、中心高变。测试只是布局几何，不证明屏幕焦点与字体都合适，真实表单仍要缩放观察。

只把南部面板换为一个直接放SOUTH的按钮，它会被拉满宽；这解释为何多个自然大小按钮先放子面板。独立画每个容器的布局管理器，不把“根用BorderLayout”误推成所有内层也同一种布局。

在课程根目录PowerShell运行`./java.ps1 -Source './L43_第12章A_模型布局与输入控件/code/NestedLayoutSizes.java'`。
