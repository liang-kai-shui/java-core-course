## 这一课要解决什么问题

程序要记住人数、价格、姓名和真假条件。如何给数据起名，又避免把不合适的数据混用？

## 1. 先看程序外壳

```java
public class VariableDemo {
    public static void main(String[] args) {
        int count = 3;
        System.out.println(count);
    }
}
```

`class`声明类；**类**可以组织程序，后面还会用来描述对象。**方法**是一段有名字、可被调用的操作；这里`main`是启动方法。先把`public static void main(String[] args)`当作完整模板使用：`public`表示可访问，`static`使启动时无需先创建该类对象，`void`表示不返回结果；第4章会用真正的调用解释它们。

花括号包住代码范围，分号结束语句。`//`到行末是注释，`/* ... */`是块注释，注释不会被执行，也不能随意嵌套。引号中的`//`属于文本，不会变成注释。

## 2. 变量与赋值

**变量**给运行中要用的数据起名，像贴着标签的格子。`int count = 3`声明类型、名字并给初值。`count = count + 1`是先取右边旧值计算，再把结果放回左边；不是数学里声称两侧永远相等。

**类型**规定可以存什么值及允许哪些操作。类比容器标签只是入门帮助；Java的引用变量并不直接把整个对象装进格子。

局部变量用之前必须确定已赋值：`int count;`本身合法，但直接输出尚未赋值的count会编译失败。不要把“局部变量未初始化”与“数组元素有默认值”混为一谈。

## 3. 常用类型先抓住用途

| 类型 | 适合的值 | 重点 |
|---|---|---|
| byte/short/int/long | 一定范围内的整数 | 首选int；很大的整数字面量加L |
| float/double | 浮点数 | 首选double；float字面量常需f；许多小数不能精确表示 |
| char | 一个UTF-16代码单元 | 如'A'、'中'；不是任意一个完整Unicode字符 |
| boolean | true或false | 不能拿0/1自动替代 |
| String | 一段文本 | 引用类型，不属于8种基本类型 |

**字面量**是直接写在源码里的值，例如`42`、`3.5`、`'A'`和`"Java"`。**常量**在本课用`final int DAYS = 7`表示赋值后不能再改的量，避免把固定意义散落成神秘数字。普通变量名用`studentCount`这类有意义的写法，常量名可用`MAX_COUNT`。

## 4. 范围、初始化与作用域

`int`范围是-2147483648到2147483647；存不下的计算不会自动变成long。运行VariableDemo观察最大值加1，它会绕回负数。不要套用C++有符号整数溢出的规则。

**作用域**指代码哪些位置可以使用一个名字。花括号内声明的局部变量通常只在相应范围可用；它不是对“这块数据在内存里什么时候消失”的完整描述。

## 动手实验

运行VariableDemo，修改人数和单价，先估算总价。运行UnicodeDemo，比较`"中".length()`与`"😀".length()`；length数的是UTF-16代码单元，后者会是2，不能把length一概称为“屏幕上的字数”。在副本中试`boolean ready = 1`、使用未赋值的局部变量，记录编译阶段的诊断。
